# [USACO2.4] 两只塔姆沃斯牛 The Tamworth Two 题解

## 题意

$10\times 10$ 的地图，`.` 为草地可通行，`*` 为障碍不可通行，`F` 是农夫 John 的起点，`C` 是奶牛的起点。两者初始都朝**北**。

第 $t=1,2,\dots$ 分钟，双方各自执行同一个动作：沿当前朝向走一格，若越界或目标格是 `*`，则原地不动并把朝向顺时针转 $90^\circ$（北 → 东 → 南 → 西 → 北）。两者同时行动，每分钟只转一次向、转向那一分钟不移动。

每分钟末检查一次：若两者站在同一格，即相遇，输出 $t$；若永远不相遇，输出 $0$。

相遇只按"分钟末同格"判定，相向而行、擦肩换位不算相遇。

## 思路

### 一、难点不在移动，而在"何时停"

移动规则已经写死，照着模拟没有难度；真正要回答的是"怎么判断永远不会相遇"。无限跑下去显然不是答案，所以需要给模拟一个有限的终止理由。

### 二、状态：决定下一步的全部信息

状态指能完全决定"下一步会怎么走"的所有信息。地图是静态的，且两人互不阻挡（对方所在的格子照常可通行），因此下一个状态只由 6 个量决定：

| 量 | 取值范围 | 含义 |
| --- | --- | --- |
| $f_x$ | $0\sim 9$ | 农夫行 |
| $f_y$ | $0\sim 9$ | 农夫列 |
| $c_x$ | $0\sim 9$ | 奶牛行 |
| $c_y$ | $0\sim 9$ | 奶牛列 |
| $d_f$ | $0\sim 3$ | 农夫朝向 |
| $d_c$ | $0\sim 3$ | 奶牛朝向 |

状态总数为

$$S = 10\times 10\times 10\times 10\times 4\times 4 = 160000 .$$

### 三、确定性系统：状态重复即死循环

转移只依赖当前状态，没有随机、没有外部输入，这是一个确定性系统。若状态 $s$ 在时刻 $j$ 和 $i$（$j<i$）各出现一次，则两次之后的轨迹逐位相同，系统从 $j$ 起进入周期循环；既然 $[j,i)$ 这一段里没有相遇，循环里也不会有，之后再也不会相遇。于是"状态重复"$\iff$"无解"，判重的理论依据就在这里。

### 四、写法 A：状态表判重

把 6 个量按**混合进制**压成一个整数，用一维 `bool` 数组标记是否走过：

```cpp
// 前四维各 10 种取值，位权 1,10,100,1000；两个朝向各 4 种，位权 10000,40000
int tdz = fy + fx * 10 + cy * 100 + cx * 1000 + df * 10000 + dc * 40000;
if (zt[tdz]) { cout << 0; return 0; }   // 该状态出现过 → 必然死循环
zt[tdz] = 1;
```

坐标 0-based 时 $0\le tdz\le 9+90+900+9000+30000+120000=159999$，恰好 160000 个取值且与状态一一对应，`bool zt[160000]` 就够用。

为什么非要压成一个整数：六维数组 `bool vis[10][10][10][10][4][4]` 同样正确，但声明冗长、下标难读；压成一维后下标就是状态编号，判重退化成一次数组访问。

### 五、写法 B：固定步数上限（参考代码采用）

状态只有 160000 种。若前 160000 分钟都没相遇，由抽屉原理必然出现重复状态（跑满 $160000$ 分钟时，连初始状态一共观察到 $160001$ 个状态，已多于 $160000$ 种），此后必然循环。所以只要**跑满一个不小于状态数的步数上限仍未相遇，就输出 0**，这与状态表判重完全等价，还省掉了标记数组。同目录的 `.cpp` 取上限 $200000$，在 $160000$ 之上留了余量。

### 六、顺序细节

代码先移动农夫再移动奶牛，看似不是"同时"。但两者这一分钟的行动输入都取自上一分钟末的状态，地图是静态的、对方位置也不构成阻挡，两人互不影响，先后顺序不改变结果，因此等价于同时移动。

## 复杂度

- 状态数上界 $S=160000$，单步转移与判定均为 $O(1)$。
- 写法 B（参考代码）：时间 $O(200000)$，空间 $O(1)$。
- 写法 A：时间 $O(S)$（$S$ 步内必然相遇或重复），空间 $O(S)$。
- 地图尺寸固定，两种写法的运行时间都可视为常数级。

## 参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<string> m(10);
    for (int i = 0; i < 10; i++) cin >> m[i];

    int fx, fy, cx, cy;
    for (int i = 0; i < 10; i++)
        for (int j = 0; j < 10; j++) {
            if (m[i][j] == 'F') { fx = i; fy = j; }
            else if (m[i][j] == 'C') { cx = i; cy = j; }
        }

    // 北、东、南、西（顺时针）
    int dx[4] = {-1, 0, 1, 0};
    int dy[4] = {0, 1, 0, -1};
    int df = 0, dc = 0;   // 初始都朝北

    for (int t = 1; t <= 200000; t++) {
        // ---- FJ 移动（基于旧状态）----
        int nfx = fx + dx[df], nfy = fy + dy[df];
        if (nfx < 0 || nfx > 9 || nfy < 0 || nfy > 9 || m[nfx][nfy] == '*') {
            df = (df + 1) % 4;      // 撞墙/障碍，只转向，不移动
        } else {
            fx = nfx; fy = nfy;
        }

        // ---- 牛移动（基于旧状态，地图只有 * 障碍）----
        int ncx = cx + dx[dc], ncy = cy + dy[dc];
        if (ncx < 0 || ncx > 9 || ncy < 0 || ncy > 9 || m[ncx][ncy] == '*') {
            dc = (dc + 1) % 4;
        } else {
            cx = ncx; cy = ncy;
        }

        // ---- 分钟末统一判相遇 ----
        if (fx == cx && fy == cy) {
            cout << t;
            return 0;
        }
    }

    cout << 0;
    return 0;
}
```

## 易错点

1. **朝向必须和增量对应**：`dx = {-1,0,1,0}`、`dy = {0,1,0,-1}` 依次对应北、东、南、西；行号向下增大，所以"北"的行增量是 $-1$。初始朝向是北（下标 0），不是东。
2. **撞墙只转不走，一次只转 $90^\circ$**：常见错误是转向后立刻再走一格，或在一分钟内连续转到能走为止。
3. **相遇在两人都动完之后判**：必须按分钟末的同格判定，不能移一步判一次，也不能把相向擦肩换位当成相遇。
4. **步数上限不能小于状态数**：用固定步数代替判重时，要观察到 $160001$ 个状态（含初始状态）才能保证重复，所以跑满 $160000$ 分钟刚好够用；上限若小于 $160000$，才可能把"实际有解"误判成无解。参考代码取 $200000$ 是留余量。
5. **状态编码的位宽与偏移**：若沿用 1-based 坐标拼位，`tdz = f[1]+f[2]*10+c[1]*100+c[2]*1000+f[0]*10000+c[0]*40000` 的取值落在 $[1111,161110]$，最大下标 $161110$ 会越过 `bool zt[160005]`；改 0-based 或把数组开够才安全。
6. **`F`、`C` 所在格是可通行的**：全图只有 `*` 阻挡，别把起点字符或对方所在格当成障碍。

## 总结

本题是"确定性模拟 + 有界性终止"的模板：先数清状态空间，再用"状态重复即循环"把无限模拟压成有界模拟。判重表和固定步数上限是同一结论的两种实现，后者代码更短，前者更容易解释正确性。

## 说明

题名中的"两只"指农夫与奶牛两个主体，代码只处理 `F`、`C` 各一个起点，与 `*.` 两种地形一起构成完整规则。
