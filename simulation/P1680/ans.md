# 奇怪的分组 题解

## 题意

把 $n$ 个人分成 $m$ 个**有标号**的组，要求第 $i$ 组的人数**严格大于**给定的 $C_i$（也就是至少 $C_i+1$ 人）。两个方案相同当且仅当各组人数对应相等，所以本质上是「每组各分多少人」的计数问题。求方案数对 $10^9+7$ 取模。

输入：第一行 $n,m$，随后 $m$ 行各一个 $C_i$；数据范围 $1\le n,m\le 10^6$，$1\le C_i\le 1000$，并保证至少存在一种方案。

因为要求「严格大于」，先把每组的 $C_i$ 预留掉，剩下的

$$
n' = n - \sum_{i=1}^{m} C_i
$$

个人还要继续分给这 $m$ 组，并且每组至少再拿到 $1$ 个。参考代码正是先做 `n -= t` 扣掉每个 $C_i$，再用 `C(n - 1, m - 1)` 出答案。

## 思路

**第一步：扣掉下限，把问题化成「每组至少 $1$ 个」。** 第 $i$ 组先预留 $C_i$ 个，这部分没有任何选择余地；预留之外，每组还至少要再拿 $1$ 个（这样人数才严格大于 $C_i$）。把每组预留的 $C_i$ 个摘出来，剩下的 $n'$ 个就要分给这 $m$ 组、每组至少 $1$ 个——两种描述互为扣掉 / 补上各自的 $C_i$，一一对应，方案数相等。这就是代码里那句循环 `cin >> t; n -= t;` 的全部作用——它把问题规模从 $n$ 压到 $n'$。

**第二步：隔板法。** 设第 $i$ 组在保底之外再拿 $b_i$ 个，则要求

$$
\sum_{i=1}^{m} b_i = n', \qquad b_i \ge 1
$$

把这 $n'$ 个物品排成一列，相邻两个物品之间有 $n'-1$ 个空隙。从这些空隙中选 $m-1$ 个插上隔板，就唯一地把队列切成 $m$ 段，且每段至少有一个物品，对应一组满足条件的 $(b_1,\dots,b_m)$；反过来，任意一组解也唯一确定一种插板位置。因此方案数为

$$
C(n'-1,\; m-1)
$$

换成代码里的写法，扣完下限后 `n` 就是 $n'$，所以答案是 `C(n - 1, m - 1)`。

也可以从非负解的角度验证：令 $c_i = b_i - 1 \ge 0$，则 $\sum c_i = n' - m$，非负整数解的个数是 $C((n'-m)+(m-1),\,m-1) = C(n'-1,\,m-1)$，与插板的结论一致。

**第三步：组合数必须取模，而且要用逆元。** 直接算会出现两个问题：一是阶乘增长极快，$n'$ 到 $10^6$ 时 $n'!$ 早就远超 `long long`；二是模运算对除法不封闭，

$$
\frac{a}{b} \bmod p \neq \frac{a \bmod p}{b \bmod p}
$$

所以不能"先取模再相除"。办法是把除法换成乘以**模逆元**。取模数 $p = 10^9+7$ 是素数，且这里参与运算的下标都小于 $p$（由代码的数组上限可推断），于是每个 $k!$ 都与 $p$ 互质，费马小定理给出 $a^{p-1} \equiv 1 \pmod p$，两边除掉 $a$ 即

$$
a^{-1} \equiv a^{p-2} \pmod p
$$

完整推导在同目录的 `1.md` 里（第 3、4 节），这里只引用结论：

$$
C(n'-1,\;m-1) \equiv \text{fact}[n'-1] \cdot \text{invf}[m-1] \cdot \text{invf}[n'-m] \pmod p
$$

**第四步：只求一次快速幂，其余逆元倒推。** 如果每个阶乘都单独求逆元，单次要 $O(\log p)$，逐个求就白费了。相邻两项的阶乘逆元之间只差一个因子：

$$
\frac{1}{(i-1)!} = i \cdot \frac{1}{i!}
\quad\Longrightarrow\quad
\text{invf}[i-1] = i \cdot \text{invf}[i]
$$

两种写法等价，参考代码采用的是它的平移形式 $\text{invf}[i] = (i+1)\cdot \text{invf}[i+1]$。于是只对最大的那个阶乘做一次费马小定理快速幂，其余从大到小递推即可，预处理从 $O(n'\log p)$ 降到 $O(n'+\log p)$。参考代码里 `invf[n] = qpow(fact[n], MOD - 2)` 接着 `for (int i = n - 1; i >= 0; i--)` 就是这一步，注意下标必须**从大到小**，否则用到的 `invf[i + 1]` 还是未赋值的 0。

## 复杂度

- 时间：读入并扣下限 $O(m)$，预处理阶乘与逆元 $O(n' + \log p)$（其中一次快速幂为 $O(\log p)$），单次查询 $O(1)$；总计 $O(n' + m + \log p)$，主要开销在预处理。
- 空间：两个长度为 $n'+1$ 的数组，$O(n')$；本实现固定开 $10^6+5$。

## 参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int MOD = 1e9 + 7;
ll fact[1000005];
ll invf[1000005];

ll qpow(ll n, ll p) {
    ll ans = 1;
    while (p > 0) {
        if (p & 1) ans = ans * n % MOD;
        n = n * n % MOD;
        p >>= 1;
    }

    return ans;
}

void init(int n) {
    fact[0] = 1;
    for (int i = 1; i <= n; i++)
        fact[i] = i * fact[i - 1] % MOD;

    invf[n] = qpow(fact[n], MOD - 2);
    for (int i = n - 1; i >= 0; i--)
        invf[i] = (i + 1) * invf[i + 1] % MOD;
}

int C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return fact[n] * invf[m] % MOD * invf[n - m] % MOD;
}

int main() {
    int n, m;
    cin >> n >> m;

    int t;
    for (int i = 0; i < m; i++) {
        cin >> t;
        n -= t;
    }

    init(n);
    cout << C(n - 1, m - 1);

    return 0;
}
```

## 易错点

1. **倒推循环写成 `for (int i = n; i >= 1; i++)`**（同目录 `c.cpp` 第 36 行）。`i` 只增不减，`i >= 1` 永远为真，循环永不结束；更糟的是它每次都在写 `inv_fact[i - 1]`，下标一路往外跑，属于越界写。倒推必须让下标单调下降，正确写法是 `i--`。
2. **阶乘漏写 `% MOD`**（`c.cpp` 第 34 行 `fact[i] = i * fact[i - 1];`）。$21!$ 就超过 `long long` 上限，几十项之后 `fact[i]` 已经是错误的值（甚至为负），再拿它求逆元、乘组合数，结果全错。必须写成 `fact[i] = i * fact[i - 1] % MOD`，让每个中间量都落在 $p$ 以内。
3. **算完没有输出**（`c.cpp` 第 40 行的 `int ans = ...` 之后直接 `return 0;`）。`ans` 算出来却没有 `cout`，程序什么都不打印；而且它算的是 $C(n,m)$，根本没读入 $C_i$、也没算本题要的 $C(n'-1,m-1)$。顺带一提，`c.cpp` 的 `qpow(int a, int b)` 也有问题：`fact[n]` 这种 `ll` 实参传进去是窄化，函数体里 `a * a` 又按 `int` 相乘会溢出，形参应统一为 `ll`（参考代码即如此）。
4. **边界情况**：$n' < m$ 时 $n'-1 < m-1$，靠 `C` 里的 `if (m < 0 || m > n) return 0;` 返回 $0$；$m=1$ 且 $n'\ge 1$ 时答案为 `C(n'-1, 0) = 1`。但这个兜底只在 $n'\ge 1$ 时管用：`init(n)` 会先用 $n'$ 当下标写 `invf[n]`（$n'=0$ 还不算越界，$n'<0$ 就直接越界写了），所以更稳妥的做法是在 `init` 之前先判掉 $n'<1$、输出 $0$。
5. **预处理范围与数组大小必须对齐**：`init(n)` 会一直写到下标 $n$（`invf[n]`），数组至少要开 $n+1$ 个位置；参考代码写死 `1000005`，因此 $n'$ 必须小于 `1000005`，否则 `fact` / `invf` 直接越界。
6. **逆元的适用前提**：费马小定理求逆元只在模数为素数、且被求逆的数不是 $p$ 的倍数时成立；换成非质数模时，分母与模数互质可以改用扩展欧几里得，不互质就得走扩展 Lucas / CRT 那一套。

## 总结

解题链条是一条直线：扣掉各组下限得到 $n'$ → 隔板法把问题变成组合数 $C(n'-1,m-1)$ → 用「阶乘 + 一次快速幂求末位逆元 + 线性倒推其余逆元」在 $O(n'+\log p)$ 内完成取模计算。三点坏味道都集中在 `c.cpp`：循环方向错、阶乘没取模、结果没输出。

## 说明

原题的条件是「第 $i$ 组人数必须**大于** $C_i$」而不是「不小于」：差的正是「每组至少再拿 $1$ 个」这一步，也正是答案取 $C(n'-1,m-1)$ 而不是 $C(n'+m-1,m-1)$ 的原因。参考代码末尾算出 $C(n-1,m-1)$ 之后没有再减 $m$，与「严格大于」是对得上的。
