# P1591 阶乘数码 题解

## 题意

有 $t$ 组询问，每组给出整数 $n$ 和数字 $a$（$0\le a\le 9$），回答：$n!$ 的十进制写法中，数字 $a$ 一共出现了多少次。

由代码可推断输入格式为：第一行一个整数 $t$，随后 $t$ 行每行一对 `n a`，每组询问单独输出一行答案。代码不依赖题面写死的 $n$ 上界，而是先读入全部询问、取其中最大的 $n$ 作为预处理上限。

## 思路

### 为什么非得高精度

阶乘增长得太快，内置整数没有一点余地：`long long` 只能精确表示到 $20!\approx 2.43\times10^{18}$，而 $21!\approx 5.11\times10^{19}$ 已经溢出，往后每乘一个数都是灾难。按题目规模 $n$ 可以到 $1000$ 量级，此时

$$\log_{10}(1000!)=\sum_{i=1}^{1000}\log_{10}i\approx 2568$$

也就是 $1000!$ 是一个约 $2568$ 位的十进制整数，任何 $64$ 位类型都装不下，只能自己用「一位存一个元素」的数组来算。

但本题最终只问「某个数字出现了几次」，并不需要把这个大数再喂给别的运算，所以用 `string` 存正序十进制、最后逐字符比较是最省事的选择：`fac[i]` 本身就是能顺序扫描的字符串，统计只需一行 `if (c - '0' == a) ans++;`。

### 大数乘法的三个关键设计

**一、倒序存储。** 乘法中第 $i$ 位与第 $j$ 位的贡献落在第 $i+j$ 位，进位方向是从低位到高位。把下标 $0$ 定义成个位，进位方向就与下标增大方向一致，循环写起来最自然。代码里的 `A[i] = a[l1-1-i]-'0'` 就是这个翻转动作。

**二、先累加、最后统一进位。** 双重循环里完全不管进位，只把每个位对的直积堆到对应槽位：

$$\text{ans}[i+j]\mathrel{+}=A[i]\cdot B[j]$$

这样「下标计算」和「进位传播」两件事被彻底解耦，不会出现边进位边修改后面还要用的元素、或者进位链越界之类的麻烦。等所有贡献堆完，再从低位往高位扫一遍统一处理：

记 $s=\text{ans}[k]+c$（$c$ 是上一位传来的进位），则这一位要做的是

$$c\leftarrow\Big\lfloor\frac{s}{10}\Big\rfloor,\qquad \text{ans}[k]\leftarrow s\bmod 10$$

两条式子的右端都必须用更新前的 $c$ 与 $\text{ans}[k]$。对应到代码，就是先把「和」落回 `ans[k]`，再算新进位、再取模；若先更新 $c$、又用新 $c$ 去取模，进位就被重复计入，结果直接错。

这一步之所以能一次扫完，是因为 $l_1$ 位数乘 $l_2$ 位数最多 $l_1+l_2$ 位：数组开 $l_1+l_2$，从 $k=0$ 扫到 $l_1+l_2-1$，最后的进位必然为 $0$，不需要额外给最高位腾位置。

另外累加阶段每个槽位的值不超过 $81\cdot\min(l_1,l_2)$。本题第二个乘数是 `to_string(i)`，长度最多 $4$，所以槽位峰值只有三百多，用 `int` 完全安全。

**三、去前导 $0$ 的时机在反转之前。** 此时 `ans` 仍是倒序（高位在末尾），所以「去掉前导 $0$」等价于「从末尾弹」，代码写成 `while (ans.size() > 1 && ans.back() == 0) ans.pop_back();`，弹完再 `reverse` 回正序。

顺序反了就是错的：若先反转，前导 $0$ 跑到开头，`pop_back()` 删掉的其实是低位真实的 $0$——`1200` 会被削成 `12`，结果直接小了一百倍。而 `size() > 1` 是保护「结果本身就是 $0$」的情形，避免把唯一的那一位也弹掉；本题的阶乘链上不会出现 $0$，但这让函数本身是通用的。

还要记住一个约定：函数内部 `A`、`B` 是倒序，而返回值已经是**正序**（下标 $0$ 是最高位），所以 `main` 里能直接 `for (int d : v) s += char('0' + d);` 拼出正确的十进制串。两套方向一旦记混，拼出来的数整个是反的，数位统计自然全错。

### 多组询问为什么要预处理到 maxN

若每组询问都从 $1$ 重新乘到 $n$，总乘法次数是 $\sum n$，最坏 $t\times\text{maxN}$ 次。而 $i!=(i-1)!\times i$ 是天然递推的，于是可以：

1. 先把全部询问读进 `qs`，一边读一边维护 `maxN`；
2. 只算一次 $1!,2!,\dots,\text{maxN}!$ 并全部存进 `vector<string> fac`；
3. 之后每组询问只是把 `fac[n]` 扫一遍数数。

这样乘法次数固定为 $\text{maxN}-1$，与 $t$ 无关，代价是空间上要同时存下所有阶乘。注意必须先读完全部询问才知道 `maxN`，这正是「离线读入 + 统一预处理」的模式。

## 复杂度

记 $D=\text{digits}(\text{maxN}!)$ 为最长阶乘的位数（$\text{maxN}=1000$ 时约 $2568$），$d(i)$ 为 $i$ 的位数。

- 时间：第 $i$ 次乘法是「长度 $d((i-1)!)$ 的数 × 长度 $d(i)$ 的数」，开销 $O\big(d((i-1)!)\cdot d(i)\big)$，总计

$$O\Big(\sum_{i=2}^{\text{maxN}}d((i-1)!)\cdot d(i)\Big)=O\Big(D\cdot\sum_{i=2}^{\text{maxN}}d(i)\Big)=O\big(\text{maxN}\cdot D\cdot\log_{10}\text{maxN}\big)$$

  注意不能把 $\sum_{i}d(i)$ 当作常数：$d(i)$ 从 $1$ 长到 $4$，$\sum_{i\le\text{maxN}}d(i)=\Theta(\text{maxN}\log_{10}\text{maxN})$，所以乘法总量比 $\text{maxN}\cdot D$ 还多一个 $\log$ 因子（$\text{maxN}=1000$ 时 $\text{maxN}\cdot D\approx2.57\times10^6$，实际约 $3.5\times10^6$，确实不止）。

  统计阶段每组 $O(D)$，共 $O(tD)$。
- 空间：保存全部阶乘 $O(\text{maxN}\cdot D)$ 位，单次乘法的临时数组 $O(D)$。

按 $\text{maxN}=1000$、$D\approx2568$ 估算，乘法总量约 $3.5\times10^6$，存储约 $1.2\times10^6$ 个字符，非常宽松。

## 参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 大数乘法：a、b 为正序十进制串，返回正序十进制 vector
vector<int> multiply(string a, string b) {
    if (a == "0" || b == "0") return {0};

    int l1 = a.size(), l2 = b.size();
    vector<int> A(l1), B(l2), ans(l1 + l2, 0);

    // 倒序：下标 0 是个位
    for (int i = 0; i < l1; i++) A[i] = a[l1 - 1 - i] - '0';
    for (int j = 0; j < l2; j++) B[j] = b[l2 - 1 - j] - '0';

    // 先累加不进位
    for (int i = 0; i < l1; i++)
        for (int j = 0; j < l2; j++)
            ans[i + j] += A[i] * B[j];

    // 最后统一进位
    int carry = 0;
    for (int k = 0; k < l1 + l2; k++) {
        ans[k] += carry;
        carry = ans[k] / 10;
        ans[k] %= 10;
    }

    // 去前导 0：此时高位在末尾
    while (ans.size() > 1 && ans.back() == 0) ans.pop_back();

    reverse(ans.begin(), ans.end());   // 恢复正序
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    vector<pair<int, int>> qs(t);
    int maxN = 1;
    for (auto &[n, a] : qs) { cin >> n >> a; maxN = max(maxN, n); }

    // 预处理所有 i! 到 maxN
    vector<string> fac(maxN + 1);
    fac[0] = fac[1] = "1";
    for (int i = 2; i <= maxN; i++) {
        vector<int> v = multiply(fac[i - 1], to_string(i));
        string s;
        for (int d : v) s += char('0' + d);
        fac[i] = s;
    }

    for (auto [n, a] : qs) {
        int ans = 0;
        for (char c : fac[n]) if (c - '0' == a) ans++;
        cout << ans << '\n';
    }
    return 0;
}
```

## 易错点

- **用 `long long` 直接算 $n!$**：$21!$ 就已经越界，$n$ 到 $1000$ 时结果有几千位，必须走大数。
- **数组开小了**：位数是 $\Theta(n\log n)$ 量级而不是 $n$ 位，只开到 $n$ 会写越界。单次乘法要开 $l_1+l_2$，别只开 $\max(l_1,l_2)$。
- **先 `reverse` 再去前导 $0$**：会误删低位真实的 $0$（`1200` → `12`）。必须在倒序状态下从末尾弹，弹完再反转。
- **进位循环没扫满**：必须扫完 $l_1+l_2$ 个槽位，最后一位也可能被进位变成非 $0$；少扫一位就会丢掉最高位。
- **漏掉 `ans.size() > 1`**：结果恰为 $0$ 时会把唯一的一位弹空，函数返回空 vector。本题不触发，但这是函数级错误。
- **正序/倒序搞混**：`A`、`B` 倒序，返回值 `ans` 正序。若误以为返回值仍倒序又反转一次，得到的数是反的，统计结果全错。
- **`maxN` 初值写错**：代码里 `maxN` 必须从 $1$ 开始（而不是 $0$），才能保证 `fac` 至少有 `fac[0]`、`fac[1]` 两个元素，`fac[0] = fac[1] = "1"` 才不会越界。
- **`a` 的类型**：询问里的 $a$ 是整数，比较要用 `c - '0' == a`，写成 `c == a` 属于类型混用。
- **每组都重算阶乘**：答案虽然对，但做了 $t\times\text{maxN}$ 量级的重复乘法；预处理到 `maxN` 才是本解法的要点。

## 总结

这题的技术核心只有一个：用「倒序存储 + 先累加不进位 + 统一进位」的经典写法实现大数乘法，再靠 $i!=(i-1)!\times i$ 的递推把所有询问共用的阶乘一次算到 `maxN`，最后把大数当字符串扫一遍数数。弄清了「去前导 $0$ 必须在反转之前」和「返回值是正序、内部数组是倒序」这两个方向约定，实现就不会翻车。
