### 1. 查找空闲区间
我的代码中采用
```cpp
int start = last_end[j];
while (true) {
    bool ok = true;
    for (int t = start; t < start + dur; t++) {
        if (busy[ma][t]) {ok = false; break;}
    }
    if (ok) break;
    start++;
}
```
可以替换为
```cpp
int s = 0;
for (int j = las_time[now] + 1; ; j++) {
    if (mac[id][j] == 0) s++;
    else s = 0;
    if (s == cost) {
        for (int k = j - cost + 1; k <= j; k++) mac[id][k] = 1;
        if (j > ans) ans = j;
        las_time[now] = j;
        break;
    }
}
```
