# P1098 [NOIP 2007 提高组] 字符串的展开 题解

## 题意

给定参数 $p_1,p_2,p_3$ 和一个由小写字母、数字、减号 `-` 组成的字符串 $s$，把形如 `a-b` 的「减号缩写」按规则展开，其余字符原样保留。

展开的**前提**是减号左右两边同类：同为数字，或同为字母；否则不展开。再加上「左边小于右边才有内容可填」，可以把规矩合成一句话：

记 $L=s_{i-1}$，$R=s_{i+1}$，$l=R-L-1$。

- $l<0$（即 $L\ge R$）：不展开，原样输出 `L-R`；
- $l=0$（$L,R$ 在 ASCII 上相邻）：展开后中间什么都没有，三个字符变成两个；
- $l>0$：把 $L$ 与 $R$ 之间被跳过的 $l$ 种字符，每种重复 $p_2$ 遍插在中间。

三种参数的分工：

- $p_1=1$：字母填小写；$p_1=2$：字母填大写；$p_1=3$：不论左端是字母还是数字，整段用 `*`。
- $p_2$：每个填充字符重复的次数，所以 $l>0$ 时插入的字符数是 $l\times p_2$。
- $p_3=1$ 正序（$L+1,\dots,R-1$），$p_3=2$ 逆序（$R-1,\dots,L+1$）。

参数组合一览（「填充字符」指那 $l$ 种字符各自的取值）：

| $p_1$ | 左端为字母 | 左端为数字 |
| --- | --- | --- |
| 1 | $L+1,L+2,\dots$，保持小写 | 数字本身 |
| 2 | 同一序列再 $-32$，即大写 | 数字本身 |
| 3 | 全部为 `*` | 全部为 `*` |

## 思路

### 用一个 $l$ 同时表达「填几种」和「逆序偏移」

代码没有显式比较 $L<R$，而是先算

$$l = s_{i+1}-s_{i-1}-1$$

这个量有两层含义：它既是 $L$ 与 $R$ **之间**被跳过的字符种数，也是正序时最后一个填充字符相对 $L$ 的偏移量。于是三种情况被一个 $l$ 的符号切开：$l<0$ 不该展开、$l=0$ 相邻无字符、$l>0$ 真填充。「左边小于右边才展开」这件事，在这里被吸收进了 $l$ 的正负号里，省掉一次独立判断。

### 逆序就是镜像偏移

正序第 $j$ 个填充字符（$1\le j\le l$）是 $L+j$；逆序要的是 $L+l,L+l-1,\dots,L+1$，第 $j$ 个恰好是 $L+(l-j+1)$。所以

$$L+\bigl(p_3=1\ ?\ j:\ l-j+1\bigr)$$

一个三元表达式就吃掉了 $p_3$。字母的大小写也复用同一个偏移，只差常数 $-32$——ASCII 里 `'a'` 与 `'A'` 的距离。

### 为什么结果要先收集进数组，再统一输出

最自然的写法是就地 `s.insert(pos, t)` 或 `s = s.substr(0,i) + t + s.substr(i+1)`，但那样会立刻破坏循环依赖的两样东西。

1. **下标的语义**。展开长度是 $l\times p_2$，插入后原串 $i$ 右侧所有字符整体后移，`s[i-1]`、`s[i+1]` 不再指向原来的邻居，之后的 `i++` 会跳字符或重复处理。
2. **长度未知**。不扫一遍算不出答案长度，就地扩容后很难再维持「扫描位置 = 原串位置」这条不变量。

代码把「计算」和「输出」拆成两趟：第一趟只把每个减号替换成展开结果 `t`（或 `"-"`、或空串）压进 `r`；第二趟按原串再走一遍，普通字符直接输出，遇减号就 `cout << r[idx++]`。原串本身全程只读，下标永远对得上。

这个方案能成立靠一条**不变量**：$s$ 中第 $k$ 个减号恰好对应 `r[k]`，即第一趟里**每个**减号都必须无条件 push 一次。代码的三条分支都守住了它——不同类 `push_back("-")`、$l=0$ `push_back("")`、正常展开 `push_back(t == "" ? "-" : t)`——所以 `idx` 不会与减号错位。反过来说，若图省事在判定前加一句 `if (i == 0 || i == (int)s.size() - 1) continue;` 把首尾减号直接跳过而不 push，就会少一项，从那里起整个输出串位。

### `t == "" ? "-" : t` 不是随手写的

$l<0$ 时循环 `for (j = 1; j <= l; j++)` 一次都不执行，`t` 保持空串，正好被这个判断翻译成「保留减号」。而 $l=0$ 的情形在更早处已经 `push_back("")` 然后 `continue`，专门绕开该判断——否则相邻字母也会被当成不展开、错误地留下减号。$l>0$ 时 `t` 必然非空，所以这个三元实际只服务于 $l<0$ 一种情况：把「无填充」顺手当作「不展开」，用一次判空同时表达两件事。

## 复杂度

设原串长度 $n$，某个减号对应的间隔为 $l$，插入字符数 $l\cdot p_2$。

- 时间：第一趟每个字符 $O(1)$ 判定，展开部分共写出 $\sum l\,p_2$ 个字符；第二趟 $O(n)$。即 $O(n+|ans|)$，$|ans|$ 是展开后长度。
- 空间：`r` 中每个减号存一项，字符总量同样 $O(|ans|)$，加上原串 $O(n)$。

字符是 ASCII 连续段，数字之间至多跳过 $8$ 个、小写字母之间至多跳过 $24$ 个，所以单个 $l$ 很小，开销只取决于答案总长度。

## 参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int p1, p2, p3;
    cin >> p1 >> p2 >> p3;
    string s;
    cin >> s;

    vector<string> r;                          // 第 k 个减号的展开结果
    for (int i = 0; i < s.size(); i++){
        if (s[i] == '-') {
            bool both_digit = isdigit(s[i-1]) && isdigit(s[i+1]);
            bool both_alpha = isalpha(s[i-1]) && isalpha(s[i+1]);
            bool ok = (both_digit || both_alpha);
            if (!ok) {                         // 两边不同类，保留减号
                r.push_back("-");
                continue;
            }

            string t = "";
            int l = s[i + 1] - s[i - 1] - 1;   // 中间被跳过的字符种数
            if (l == 0) {                      // 相邻字符，展开为空
                r.push_back("");
                continue;
            }
            for (int j = 1; j <= l; j++) {
                // 先算这一位填什么字符
                char ch;
                if (isalpha(s[i - 1])) {
                    if (p1 == 1) {
                        ch = s[i - 1] + (p3 == 1 ? j : l - j + 1);
                    } else if (p1 == 2) {
                        ch = s[i - 1] + (p3 == 1 ? j : l - j + 1) - 32;
                    } else ch = '*';
                } else {
                    if (p1 == 3) ch = '*';
                    else ch = s[i - 1] + (p3 == 1 ? j : l - j + 1);
                }

                // 每个字符重复 p2 次
                for (int k = 1; k <= p2; k++) t += ch;
            }

            r.push_back(t == "" ? "-" : t);    // l < 0 时 t 为空，即不展开
        }
    }

    int idx = 0;
    for (int i = 0; i < s.size(); i++) {
        if (s[i] == '-') {
            cout << r[idx++];
        } else {
            cout << s[i];
        }
    }

    return 0;
}
```

## 易错点

1. **首尾的减号会越界**。代码直接读 `s[i-1]`、`s[i+1]`，没有 `i > 0 && i + 1 < (int)s.size()` 之类的保护。$i=0$ 时 `s[i-1]` 是负下标，转成 `size_t` 后指向串前内存，是实打实的未定义行为；$i=n-1$ 时读到的是 `s[s.size()]`，C++11 起读它返回 `'\0'`、勉强合法，但“末尾正好是 `'\0'` 才会被判成不同类”属于脆弱的巧合，换成 `s.at()` 或别的标准库就翻车。稳妥做法是先挡边界：首尾的减号当普通字符输出。
2. **`isalpha`/`isdigit` 传入负值 `char` 是未定义行为**。这组函数只接受 `EOF` 或 `unsigned char` 能表示的值；若 `char` 有符号且字节 $\ge 128$，直接传进去会越界访问 `ctype` 表。当前靠“串里只有小写字母、数字、减号”才没出事，稳健写法是 `isdigit((unsigned char)s[i-1])`。
3. **`l=0` 的提前返回不能省**。漏掉它，`a-b` 这种相邻字母会退化成保留减号；反过来若把 $l<0$ 也当「输出空」，`c-a` 又会丢掉减号。$l$ 的正负和 $l=0$ 这两个边界必须分头处理。
4. **`p1==2` 用 `-32` 硬转大写**，隐含前提是输入字母为小写。若左端本身就是大写字母，$L+j-32$ 会算出 `!` 之类的非字母字符；同理 `p1==1` 也不会把大写折回小写。代码把「输入只含小写字母」当成了既定事实。
5. **两趟遍历的不变量别破坏**。`r[idx++]` 假定每个减号在第一趟恰好 push 一次，想跳过某个减号时必须 push `"-"` 而不是 `continue`，否则从该处起全部输出错位。
6. `i < s.size()` 是 `int` 与 `size_t` 的混合比较，开 `-Wall` 会有符号转换警告；逻辑无害，但写成 `int n = s.size();` 更干净。

## 总结

算法本体只是逐字符模拟，难点全在边界：$l<0$、$l=0$、$l>0$ 三种情形，加上「每个减号恰好对应 `r` 的一项」这条隐性不变量。把展开计算与答案输出分成两趟、用原串下标来对齐替换结果，就一次性避开了就地插入导致的下标错乱。
