# P1024 [NOIP 2001 提高组] 一元三次方程求解 题解

## 题意

给定三次方程

$$f(x)=ax^{3}+bx^{2}+cx+d=0$$

题面保证它在 $[-100,100]$ 上恰好有三个实根，并且任意两个根的距离至少为 $1$。要求把这三个根从小到大输出，每个根保留两位小数。

由代码可推断：四个系数以 `double` 读入；三个根按升序输出、以空格分隔，末尾也带一个空格，且没有输出换行（见 `printf("%.2f ", ...)`）。

## 思路

### 一、为什么可以按长度为 1 的整数区间枚举

三次方程最多只有三个实根，而题面保证根间距 $\ge 1$。把 $[-100,100]$ 切成 $[i,i+1]\ (i=-100,-99,\dots,99)$ 共 $200$ 个单位区间后，**任何一个区间内部最多只含一个根**：若某区间内有两个根，它们之间的距离必然小于 $1$，与保证矛盾。

这条保证是整道题成立的支点：它把「在连续实数里找根」变成「在 200 个格子里各自判定有没有根」，而且一旦判定某个格子有根，二分求出的那个根就是该格子里的全部答案，不会漏掉同格子的第二个根。同时题面保证三个根都落在 $[-100,100]$ 内，所以区间外的部分不需要考虑。

### 二、零点定理给出二分的合法性

$f$ 是多项式，处处连续。若 $f(l)\cdot f(r)<0$，由零点定理（介值定理的直接推论）必存在 $c\in(l,r)$ 使 $f(c)=0$；再结合上一节的唯一性，这个根是唯一的，二分法就有了明确的收敛目标。

代码中的二分维护的不变式是「$f(l)$ 与 $f(r)$ 异号」：

- 若 $f(l)\cdot f(\text{mid})\le 0$，说明根在 $[l,\text{mid}]$，令 $r=\text{mid}$；
- 否则 $f(\text{mid})$ 与 $f(l)$ 同号、与 $f(r)$ 异号，令 $l=\text{mid}$。

两种情况下根都不会被切掉，区间长度每轮减半，最终 $l$ 与真实根任意接近，输出 $l$ 即可。

### 三、端点为什么这样处理（本题最容易被漏掉的部分）

如果根恰好落在整数点上，那么 $f$ 在该点为 $0$，乘积 $f_1\cdot f_2$ 也随之变成 $0$，严格不等式 $f_1\cdot f_2<0$ **不成立**，符号判定根本抓不到这种根。所以端点必须显式判断。

但端点是相邻两个区间共用的：整数 $k$ 既是 $[k-1,k]$ 的右端点，也是 $[k,k+1]$ 的左端点。**两端都判就会输出两遍**。代码的选择是每个区间只判右端点 `f(i+1)`、不判左端点 `f(i)`，于是 $[-100,100]$ 中每个整数 $k$ 恰好作为 $[k-1,k]$ 的右端点被覆盖一次，不重不漏。

唯一的例外是 $k=-100$：它没有左边的区间 $[-101,-100]$，自然轮不到「作为右端点」的机会，只能在循环之前单独判一次 `f(-100)`。这就是循环外那个 `fabs(f(-100)) < 1e-6` 特判的全部来历——不是随手打的补丁，而是端点归属规则留下的唯一覆盖缺口。

判完右端点后直接 `continue`：右端点是根时，区间内部不可能还有根（间距 $\ge 1$），也不需要进行二分。至于下一轮区间以这个根为左端点会不会重复输出，**理想情况**是不会的：$f_1$ 在这一点上等于 $0$，乘积为 $0$，严格不等式不成立。但代码里的 $f_1$ 是浮点算出来的，通常落在一个远小于 $10^{-6}$ 的残差上，大小和符号都由各项的舍入决定（系数、$x$ 越大残差越大，$|x|$ 接近 $100$ 时可以到 $10^{-9}$ 上下）；一旦它与 $f(i+2)$ 异号，`f1 * f2 < 0` 仍然成立，二分从 $l=i$ 出发只会把 $r$ 一路折回 $i$，最终又输出一次 $i$。这个缺口靠「$f_1$ 等于 $0$」的假设是堵不住的，见「易错点」第 5 条。

### 四、二分 100 次为什么够精度

初始区间长度为 $1$，第 $k$ 次二分后长度变为 $2^{-k}$，而真实根始终被夹在区间内，所以误差上界就是当前区间长度。要四舍五入到两位小数，只需 $2^{-k}$ 小于 $0.005$ 量级，$k\approx 8$ 实际上就够了；代码取 $100$ 次，长度降到约 $8\times 10^{-31}$，早已低于题面要求的精度，把「精度不足」这一风险完全消除。代价也很小：$200$ 个区间、每轮两次函数求值，总共不过几万次求值，耗时可以忽略。这类题里「多二分几十次」几乎永远比「算清楚需要几次」更省事。

### 五、为什么用 `fabs` 判零

浮点运算并不精确：$a x^3+bx^2+cx+d$ 在 $|x|=100$ 这种量级上会积累舍入误差，理论上等于 $0$ 的表达式可能算出一个 $10^{-13}$ 之类的非零值。若写 `f(-100) == 0`，绝大多数情况下都会漏判。因此用

$$|f(x)|<10^{-6}$$

这类容差判零。与「符号判定用严格不等号」配合时，分工本来很清楚：靠近零的端点交给 `fabs` 分支负责输出，严格异号的区间交给二分负责求解，两套判据各管一段；只是残差偶尔会漏进符号判定，那一处见易错点 5。

### 六、算法的整体形状

遍历 $200$ 个区间：先看右端点是不是根，是就输出并跳过；否则看两端是否异号，异号就二分 $100$ 次求出唯一根；用计数器控制到三个根就提前退出。三个根的下标区间互不重叠，输出天然升序。

## 复杂度

- 时间复杂度：$O(1)$，常数级。枚举 $200$ 个区间，每个区间至多二分 $100$ 轮，每轮两次函数求值，函数求值次数上界约 $4\times 10^{4}$（实际只有至多三个区间会真正进入二分，远小于这个上界），每次求值不过几次乘加。
- 空间复杂度：$O(1)$，只有常数个标量。

## 参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;

double a, b, c, d;

double f(double x) {
    return a * x * x * x + b * x * x + c * x + d;
}

int main() {
    cin >> a >> b >> c >> d;

    int cnt = 0;
    // 先检查 -100 是否是根
    if (fabs(f(-100)) < 1e-6) {
        printf("%.2f ", -100.0);
        cnt++;
    }

    for (int i = -100; i <= 99 && cnt < 3; i++) {
        double x1 = i, x2 = i + 1;
        double f1 = f(x1), f2 = f(x2);

        // 如果右端点是根
        if (fabs(f2) < 1e-6) {
            printf("%.2f ", x2);
            cnt++;
            // 因为根间距 >= 1，下一个根肯定不在 i+2 之前
            // 但循环会 i++，所以下次是 i+2。没问题。
            // 不过，如果 i+1 是根，那么 (i, i+1) 之间不可能有根，所以不用二分。
            continue;
        }

        // 如果区间内有根
        if (f1 * f2 < 0) {
            double l = x1, r = x2;
            for (int k = 0; k < 100; k++) {
                double mid = (l + r) / 2;
                if (f(l) * f(mid) <= 0) r = mid;
                else l = mid;
            }
            printf("%.2f ", l);
            cnt++;
        }
    }

    return 0;
}
```

## 易错点

1. **只写 `f1 * f2 < 0`**：整数根会让乘积为 $0$，条件不成立，整根漏掉。端点必须用 `fabs` 单独判。
2. **两个端点都判**：整数根会被左右两个区间各输出一次，答案变成重复的根。本题采用「只判右端点 + 特判 $-100$」来保证每个整数点恰好被覆盖一次。
3. **忘记 $-100$ 特判**：$-100$ 没有左邻区间，若它本身是根就永远输出不到。
4. **用 `== 0` 判根**：浮点舍入会让理论上的零变成 $10^{-13}$，必须带容差。注意容差也不要取太大，否则会把「靠近端点的小值」误判成根。
5. **右端点判完了，下一区间的左端点残差没兜住**：`|f2| < 1e-6` 只保证当前这一轮不出错，下一轮 `f1` 取到的仍是同一个根的浮点残差——它满足 `fabs(f1) < 1e-6`，却一般不等于 $0$，大小和符号都不可控（系数、$x$ 越大残差越大，$|x|$ 接近 $100$ 时可到 $10^{-9}$ 上下）。若它与 `f(i+2)` 异号，`f1 * f2 < 0` 照样成立，二分从 $l=i$ 出发每轮都把 $r$ 折向 $i$，100 轮后输出的还是 $i$——同一个根打印两遍；而 `cnt < 3` 的名额被它占掉，后面的真根就漏了。实测 `0.2 -2 5.4 -3.6`（根 $1,3,6$）输出 `1.00 3.00 3.00`，`0.1 -0.75 1.65 -1`（根 $1,2.5,4$）输出 `1.00 1.00 2.50`，两组输入都满足题面全部约束。补法：给二分再加一条 `fabs(f1) >= 1e-6` 的前置条件，或者在判到右端点是根时把 `i` 再自增一次，让下一轮从 $[i+2,i+3]$ 开始。
6. **循环条件里的 `cnt < 3`**：这是提前退出的剪枝，理论上删掉也能得到正确答案（只是多跑几个区间），但保留它可以少做无用的判定。
7. **输出细节**：代码用 `"%.2f "`，三个数之间靠空格分隔，末尾多出一个空格且没有换行。多数评测能接受，抄写时不要擅自改成逗号分隔。

## 总结

这道题的难点不在二分模板，而在「把哪些情况交给谁处理」：根间距 $\ge 1$ 保证了单位区间内的唯一性，零点定理保证了异号区间内二分一定收敛，端点归属规则（每个区间只认右端点、全局补一个 $-100$）在端点值被判成零之后也保证整数根不漏不重——只差最后这一步「下一区间不再被残差判成异号」没兜住（见易错点 5）。把这三件事对齐，剩下的就是一次普通二分。
