# 洛谷 P2249 二分查找模板 题解

## 题意

给定一个长度为 $n$ 的非降序（单调不降）整数序列 $a_1, a_2, \dots, a_n$，再进行 $m$ 次询问，每次询问一个值 $v$：

- 若 $v$ 出现过，输出它**第一次**出现的下标（从 $1$ 开始）；
- 若没有出现过，输出 $-1$。

由代码可推断输入为 $n, m$ 两个整数，随后是 $n$ 个数，再随后是 $m$ 个询问值；输出时用空格逐个隔开。本题的难点全部集中在"第一次"这三个字上：普通二分只要找到一个等于 $v$ 的位置就收工，而这里必须是最左边的那一个。

## 思路

### 1. 单调性把"查找"变成"判定"

序列不降，所以对固定的 $v$，条件 $a_{\text{mid}} \ge v$ 关于 mid 是"先假后真"的：一旦某个位置满足，它右边的所有位置都满足。于是"第一个满足条件的位置"可以用二分夹出来，取到位置后再检查该位置的值是否恰好等于 $v$，就能区分"出现"与"没出现"。

代码选择了等价的另一条路线：不额外校验，而是用 `ans` 在命中的瞬间记下位置，最后用 `ans == -1` 表示不存在。

### 2. 命中后为什么必须继续往左收缩

`a[mid] == val` 只说明 mid 是"某一个"合法位置，不是最左的。因为序列不降，所有等于 $v$ 的元素挤在一段连续区间里，这段区间的左端点一定在 $[l, \text{mid}]$ 内，绝不会落在 mid 的右边。所以命中之后要把 mid 本身和它右边一起丢掉：

$$ r = \text{mid} - 1 $$

继续在左半段里找"是否还有更靠左的 $v$"。每命中一次，区间就往答案逼近一步；等区间被挤空（$l > r$）时，最后一次命中的位置就是最左的 $v$。

反过来，若命中分支写成 `l = mid + 1`，得到的是**最后一次**出现的位置，方向正好写反 —— 这是本题最常见的错误。

### 3. ans 为什么要单独记录

这版模板是"夹逼"式的：命中后 `r = mid - 1`，把 mid 排除出了区间。区间最终变空时，$l$ 停在插入位置（第一个 $\ge v$ 的下标，可能恰好等于 $n$）、$r$ 退到 $l - 1$。单看 $l$ 既可能越界，也可能指向一个根本不等于 $v$ 的位置，所以想靠它给出答案，就必须再补一次 `l < n && a[l] == val` 的校验。`ans` 的作用就是在命中的瞬间把这个信息固定下来，省掉事后校验。

因此只能在命中那一刻先存下来：

```cpp
if (a[mid] == val) {
    r = mid - 1;      // 继续往左找更小的合法位置
    ans = mid + 1;    // 先记下当前位置（转成 1 起下标）
}
```

由于每次命中都发生在更靠左的区间里，最后一次写入 `ans` 的值必然是最小下标，天然满足"第一次出现"；而 `ans` 初值取 $-1$，未命中时就原样返回，恰好对应"不存在输出 $-1$"。一个变量同时承担了"记录答案"和"标记不存在"两件事。

### 4. mid 的更新位置

代码在循环之前算一次 mid，之后每次循环体**末尾**再重算一次：

```cpp
int mid = (l + r) / 2;
while (l <= r) {
    // ... 只根据 a[mid] 调整 l 或 r ...
    mid = (l + r) / 2;
}
```

这个位置能成立，靠的是 `while (l <= r)` 这道前置门：只有区间非空时才会用到 mid，而此时

$$ l \le \left\lfloor \frac{l+r}{2} \right\rfloor \le r $$

恒成立，mid 一定落在区间内部，访问 `a[mid]` 不会越界。它的好处是三种分支行为统一：先判断、再缩 l 或 r、最后统一取新中点。

代价是区间变空退出前还会白算一次（此时 mid 可能落在 $[l, r]$ 之外，但已经不会被访问，无害）；而且这种写法容易让人误以为 mid 是"循环外维护的状态"。更常见也更稳妥的写法是把 `int mid = l + (r - l) / 2;` 放在循环体第一行 —— 只要记住"每轮进入循环体后 mid 必须按当前区间重新算一遍"，就同样正确。真正危险的是只在部分分支里更新 mid：另一个分支会拿着旧下标反复比较，逻辑错乱甚至死循环。

### 5. while (l <= r) 的可行性

两点保证：

- **必停**：`r = mid - 1` 和 `l = mid + 1` 每轮都至少裁掉 mid 这一格，区间长度严格变小且有限。
- **不漏**：循环结束时恰好 $l = r + 1$，区间为空，没有剩余元素未检查；若把 `<=` 写成 `<`，当 $l = r$ 时最后一个元素就被提前漏掉了。

死循环则来自相反的方向：闭区间模板里若写 `r = mid`（而不是 `mid - 1`），当 $l = r$ 时 mid 恒等于 $l$，区间不再缩小，程序卡死。

### 6. 三种模板对比

| 模板 | 区间形式 | 循环条件 | 收缩方式 | 答案在哪里 |
| --- | --- | --- | --- | --- |
| A（本题代码） | 闭区间 $[l, r]$ | `l <= r` | `l = mid + 1` / `r = mid - 1` | 由 `ans` 记录，未命中为 $-1$ |
| B 左闭右开 | $[l, r)$ | `l < r` | `l = mid + 1` / `r = mid` | $l$ 即第一个 $\ge v$ 的位置，需再判 $l < n$ 且 $a_l = v$ |
| C 二分答案式 | 哨兵 $l = -1,\ r = n$ | `l + 1 < r` | `l = mid` / `r = mid` | $r$ 即第一个 $\ge v$ 的位置，同样需判越界与相等 |

B、C 两版不设 `ans`，靠循环不变式让答案自己浮出水面（B 本质就是 `std::lower_bound`），代价是循环结束后必须补一次"下标是否越界、值是否相等"的校验；A 版把校验融进了 `ans` 的初值，写起来最短，也最贴合本题"不存在输出 $-1$"的输出要求。三版的 mid 都建议写成 `l + (r - l) / 2`，避免 $l + r$ 溢出。

## 复杂度

- 单次询问：每轮区间长度至少减半，共 $O(\log n)$ 次比较与数组访问；$m$ 次询问总时间 $O(m \log n)$；
- 空间：$O(n)$ 用于存序列，二分本身额外空间 $O(1)$。

## 参考代码（C++17）

```cpp
// https://www.luogu.com.cn/problem/P2249

#include <bits/stdc++.h>
using namespace std;

int bs(const vector<int>& a, int val) {
    int l = 0, r = (int)a.size() - 1, ans = -1;
    int mid = (l + r) / 2;
    while (l <= r) {
        if (a[mid] == val) {
            r = mid - 1;     // 命中后继续往左收缩
            ans = mid + 1;   // 记录位置（转成 1 起下标）
        }
        else if (a[mid] < val) l = mid + 1;
        else r = mid - 1;

        mid = (l + r) / 2;   // 循环末尾统一重算中点
    }

    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    for (int i = 0; i < m; i++) {
        int v;
        cin >> v;
        cout << bs(a, v) << ' ';
    }

    return 0;
}
```

## 易错点

- **循环条件写成 `l < r`**：$l = r$ 时还剩一格没检查，答案是错的且往往"差一位"。
- **命中后写 `l = mid + 1`、或命中就 `return mid`**：前者求成最后一次出现，后者只保证找到一个而不保证最左。
- **闭区间里写 `r = mid`**：区间不缩小，死循环；闭区间必须用 `mid - 1` 和 `mid + 1`。
- **`ans = mid` 少加 1**：下标差一位；**`ans` 忘记初始化成 `-1`**：未命中时输出不确定值。
- **`mid` 只在部分分支里更新**：另一分支会拿旧 mid 做比较，可能死循环。
- **`(l + r) / 2` 溢出**：$l + r$ 最大约 $2n$，$n$ 超过约 $1.07 \times 10^9$ 时就超出 int 上限；模板里更稳的写法是 `l + (r - l) / 2`。
- **依赖有序性**：二分正确性完全建立在"序列非降"之上，输入无序时"第一次出现"本身就没有意义。
- **输出格式**：代码用空格逐个输出，末尾会多出一个空格，属于常规写法；不要自行插入换行打乱顺序。

## 总结

本题是"找第一个满足条件的位置"的最小模型：单调不降 → 二分定位 → 命中不返回、继续往左收 → 用 `ans` 兜住最后一次命中；`while (l <= r)` 配 `mid - 1 / mid + 1`，保证区间必缩、必停、不漏元素。口诀：**命中别急着返回，往左挤到挤不动；答案不在 l、r 上，而在 ans 里。**

## 说明

本题输入保证序列单调不降，代码未做任何有序性校验，直接对读入的原数组二分，正确性完全依赖输入本身非降序——此处按代码行为记录。
