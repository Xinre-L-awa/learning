# P5019 铺设道路 题解

## 题意

一条路上依次排列着 $n$ 块区域，第 $i$ 块的下陷深度为 $a_i$。每天可以选择一段连续区间 $[L,R]$（$1\le L\le R\le n$），给其中每一块区域各填 $1$ 个单位的土（即这些区域的下陷深度都减少 $1$）；操作的前提是区间内每一块区域在填之前都还没有被填平（下陷深度不为 $0$）。求填平整条道路所需的最少天数。

由代码可推断：输入先给出区域块数 $n$，随后给出 $n$ 个整数，依次是各块区域的下陷深度（代码里这个数组被命名为 `d`）；输出一个整数，即最少天数。数据的具体范围不在代码中体现，因此不在此写死。

## 思路

记 $a_0=0$（把第 $0$ 块看作一块虚拟的、深度为 $0$ 的哨兵）。答案就是

$$
\text{ans}=a_1+\sum_{i=2}^{n}\max(0,\;a_i-a_{i-1}),
$$

这正是代码 `ans = d[0]` 加上循环里那句"只在 `d[i] > d[i-1]` 时累加差值"在做的事。下面给出两种理解。

### 视角一：差分——一次操作就是差分数组上的一次配对转移

令 $a_{n+1}=0$，差分 $b_i=a_i-a_{i-1}\;(1\le i\le n+1)$。因为 $b$ 的总和为 $a_{n+1}-a_0=0$，所以"正部之和"与"负部绝对值之和"相等。把它记作

$$
S=\sum_{i=1}^{n+1}\max(0,b_i)=\sum_{i=1}^{n}\max(0,a_i-a_{i-1}),
$$

最后一步是因为 $b_{n+1}=a_{n+1}-a_n=-a_n\le 0$，永远不贡献正部。

一次操作把 $a_L,\dots,a_R$ 各减 $1$，对差分的效果只有两处：$b_L$ 减 $1$，$b_{R+1}$ 加 $1$。也就是说，每次操作最多只能把 $S$ 减少 $1$（$b_L$ 变小才可能削掉一个正数，而 $b_{R+1}$ 变大只会让正部不降）。于是**任何**方案都至少需要 $S$ 次操作，这是下界。

下界同时是可达的：把满足 $b_i>0$ 的位置与它右侧满足 $b_j<0$ 的位置按顺序配对，每一对 $(L,R+1)$ 就对应一次形如 $[L,R]$ 的操作，配对完后 $S$ 恰好被扣成 $0$。于是最少操作数 $=S$，即答案。

这个视角也解释了为什么公式里**只有上升量**：一次操作相当于把 $L$ 处的一单位正差分转交给 $R+1$——$L$ 处减 $1$ 恰好消耗掉该位置的一单位正差分，所以正差分有多少，就必须有多少次操作以它为左端；而 $R+1$ 处加 $1$ 落在"下降处"（负差分）时只是把它往 $0$ 推，被动吸收，不会要求额外操作。

### 视角二：贪心——凹陷处被左边更高的部分顺带填掉

把 $a_i$ 想成柱状图里第 $i$ 根柱子的高度（需要垫的土层数），一次操作就是给一段连续柱子各加一层土。

* 若 $a_i\le a_{i-1}$：第 $i$ 块需要的 $a_i$ 层土，可以完全搭在左边那块的"车"上——每当左边的操作填到某一层、而这一层在 $i$ 处还没填到，就把区间右端延伸到 $i$ 即可（区间内依然每块都非零），一点都不多花。所以 $i$ 处被左边更高的部分**顺带填掉**，不新增天数。
* 若 $a_i>a_{i-1}$：多出来的 $a_i-a_{i-1}$ 层是"从左边借不到"的。左边最多只有 $a_{i-1}$ 层那么高，而任意一次覆盖第 $i$ 块第 $k$ 层（$k>a_{i-1}$）的操作，都不可能同时覆盖第 $i-1$ 块（否则会把它填成负数），于是这一层必须新开一次操作。故至少要新增 $a_i-a_{i-1}$ 天，且这些天可以由"左端点设在 $i$、右端尽量延伸"的操作恰好凑出来。

所以下界为 $a_1+\sum_{i\ge2}\max(0,a_i-a_{i-1})$。要把它收紧成等式，按层构造即可：把柱子从第 $1$ 层往上逐层处理，在第 $k$ 层对所有满足 $a_i\ge k$ 的极大连续段各做一次操作。处理到第 $k$ 层时，段内每块柱子都已经填过 $k-1$ 层、还剩至少 $1$ 层，因此"区间内都不为 $0$"的合法性自然成立。第 $k$ 层需要的操作次数就是集合 $\{i:a_i\ge k\}$ 的连续段个数；把 $k$ 从 $1$ 加到 $\max a$，位置 $i$ 只在 $k\le a_i$ 且（$i=1$ 或 $a_{i-1}<k$）时作为某个段的首块被计一次，合计恰好是上面的下界。上下界相等，贪心最优。

这也顺带说明：**下降处（凹陷）永远不花额外的天数，只有台阶的抬升处才需要新掏天数。**

### 代码为什么这么写，ans 初值为什么是 `d[0]`

公式里 $i=1$ 那一项是 $\max(0,a_1-a_0)$，而差分视角已经把哨兵设成 $a_0=0$，所以这一项就是 $a_1$ 本身，非负，不需要 `max`。代码把它单独提出来当初始值：

$$
\text{ans}\leftarrow d[0],\qquad \text{ans}\mathrel{+}=\max(0,d[i]-d[i-1])\quad(i=1,\dots,n-1)
$$

注意这是 $0$ 基下标：`d[0]` 对应 1 基的 $a_1$，循环里的 `d[i]` 与 `d[i-1]` 对应 $a_{i+1}$ 与 $a_i$。若把初值写成 $0$，就会漏掉第一块自己那 $a_1$ 层——它左边没有更高的部分可以顺带它，只能靠自己"开"出 $a_1$ 次操作，所以 $a_1$ 必须计入。

同时这也解释了为什么整个求解只需 $O(n)$ 的一遍扫描：每个位置只需要和前一个位置比一次大小，既不必真的把差分数组 $b$ 建出来，也不必逐层模拟或逐天模拟。

## 复杂度

* 时间复杂度：$O(n)$。读入 $n$ 个数，每个数只与它的前一个数比较一次并做 $O(1)$ 的累加。
* 空间复杂度：$O(n)$，用于存储整条道路；若改成边读边算（只保留上一个数与累加器），额外空间可降到 $O(1)$。

## 参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> d(n);
    for (int i = 0; i < n; ++i) {
        cin >> d[i];
    }

    // 第一天填第 1 个坑需要的天数
    long long ans = d[0];

    // 从第 2 个坑开始遍历
    for (int i = 1; i < n; ++i) {
        // 如果当前坑比前一个坑深，需要额外花天数
        if (d[i] > d[i - 1]) {
            ans += d[i] - d[i - 1];
        }
    }

    cout << ans << "\n";

    return 0;
}
```

## 易错点

1. **把 `ans` 初值写成 `0`**：这样会漏掉 $a_1$ 这一项，答案偏小。第 $1$ 块左侧没有更高的部分可以顺带它，那 $a_1$ 层必须各开一次操作，所以初值必须是 `d[0]`。
2. **循环下标从 `0` 开始**：`i = 0` 会访问 `d[-1]`，越界。循环必须从 `i = 1` 起，让 `d[i]` 与 `d[i-1]` 成对出现。
3. **错误地累加下降量或绝对值**：写成 `ans += abs(d[i] - d[i-1])` 得到的是总变差，比答案大；写成 `ans += d[i-1] - d[i]` 则方向反了。只有上升量才是"新开的天数"。
4. **模拟逐天或逐层填充**：按层统计 $\{i:a_i\ge k\}$ 的连续段数是 $O(n\cdot\max a)$，容易超时。正确做法是用"相邻两项之差"把这层循环压缩掉，只在一次扫描中累加上升量即可。
5. **用 `int` 累加**：答案的量级随 $n$ 与 $d_i$ 一起增长（反复"深—浅—深"的锯齿形最耗天数），`int` 有溢出风险；代码用 `long long` 累加是稳妥的。
6. **数组名 `d` 有迷惑性**：它存的是原数组（下陷深度），**不是**差分数组；差分只是隐含在 `d[i] - d[i-1]` 这个比较里。别把 `d` 二次误用成差分。
7. **代码假定 $n\ge1$**：它无条件访问 `d[0]`，若输入允许 $n=0$ 需要额外特判；$n=1$ 时循环不执行、直接输出 `d[0]`，这一情形是正确的。

## 总结

一句话：把"区间 $-1$"看作差分数组上的正负配对转移，最少操作数就是正差分之和

$$
\sum_{i=1}^{n}\max(0,\;a_i-a_{i-1})\quad(a_0=0),
$$

从贪心角度看则是"凹陷处被左边更高的部分顺带填掉，只有抬升处才需要新开操作"。两种说法给出同一个 $O(n)$ 一遍扫描，`ans` 的初值 `d[0]` 就是哨兵意义下的 $a_1-a_0$。
