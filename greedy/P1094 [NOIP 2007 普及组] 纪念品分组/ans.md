# P1094 [NOIP 2007 普及组] 纪念品分组 题解

## 题意

有 $n$ 件纪念品，第 $i$ 件的价格为 $a_i$，另有上限 $w$。要把所有纪念品分组，满足：

- **每组至多两件**；
- 组内价格之和不超过 $w$。

求最少的组数。由代码可推断，输入先给出 $w$，再给出 $n$，随后是 $n$ 个价格。

这是一个"尽量让两件凑成一组、剩下的单独成组"的装箱问题，目标是最小化组数，所以核心矛盾在于：哪些两件能凑成一组，才能让"单飞"的件数最少。

## 思路

### 1. 排序后从最大的一件入手

把价格从小到大排序，得到 $a_1 \le a_2 \le \dots \le a_n$，当前待处理的区间记作 $a[i..j]$，其中 $a_i$ 是剩余元素中最小的，$a_j$ 是最大的。

决策永远从 $a_j$ 开始：它是全场最大的、最"难"配的，如果它的去向悬而未决，剩下的问题就无法收缩。它能容纳的伙伴上限是剩余容量

$$r = w - a_j,$$

任何与它同组的元素 $a_k$ 必须满足 $a_k \le r$。

- 若 $a_i + a_j > w$：连全场最小的 $a_i$ 都放不进去，而剩余元素都满足 $a_k \ge a_i$，于是 $a_k + a_j \ge a_i + a_j > w$，$a_j$ 与谁都无法同组，只能**单独一组**。
- 若 $a_i + a_j \le w$：$a_j$ 一定能和某件配对，问题只剩"挑谁"。教科书双指针挑最小的 $a_i$；而 `ans.cpp` 挑的是除 $a_j$ 自身之外、**不超过 $r$ 的最大元素**（`upper_bound(...) - 1`）。下面用交换论证说明：只要伙伴合法，挑谁得到的组数都一样，所以这两种写法等价。

### 2. 交换论证：贪心选择不会吃亏

**引理（贪心选择性质）**：设在问题 $a[i..j]$ 上存在最优解 $S$，则一定存在一个最优解，它给 $a_j$ 安排的分组方式与贪心选择一致。

按 $a_j$ 在 $S$ 中的处境分类讨论：

1. $a_i + a_j > w$。如前所述 $a_j$ 与任何剩余元素都无法同组，$S$ 中它必然单独一组，与贪心完全一致。
2. $a_i + a_j \le w$，但 $S$ 中 $a_j$ 单独一组、且 $a_i$ 也单独一组。此时把 $a_i$ 与 $a_j$ 合为一组，合法性由 $a_i + a_j \le w$ 保证，而分组数减一，居然优于"最优解"，矛盾。故这种情形不会在最优解中出现。
3. $a_j$ 单独一组，而 $a_i$ 与某个 $a_k$ 一组。把 $a_i$ 从 $a_k$ 身边拆下来、与 $a_j$ 组成新组：新组合法，$a_k$ 改回单独一组，分组总数不变，得到 $S'$ 且 $|S'| = |S|$。
4. $a_j$ 与 $a_k$ 一组，而 $a_i$ 单独一组。把 $a_i$ 与 $a_k$ 的位置互换：$a_i + a_j \le w$ 合法，$a_k$ 单独一组，分组总数同样不变，$|S'| = |S|$。
5. $a_j$ 与 $a_k$ 一组，$a_i$ 与 $a_m$ 一组。交换 $a_k$ 与 $a_i$：新组 $a_i + a_j \le w$ 合法；另一组用到 $a_m \le a_j$，故 $a_k + a_m \le a_k + a_j \le w$ 也合法。分组数不变，$|S'| = |S|$。

于是任何最优解都能在不增加组数的前提下改造成"按贪心规则给 $a_j$ 找伙伴"的解，贪心选择是安全的。

**再看"挑最大的合法伙伴"为何也行**：设贪心伙伴是 $a_p$（$a[0..j-1]$ 中不超过 $r$ 的最大者）。最优解里与 $a_j$ 同组的 $a_k$ 必然也满足 $a_k \le r$，故 $a_k \le a_p$。交换 $a_k$ 与 $a_p$ 的位置后，$a_k$ 接手 $a_p$ 原来的伙伴（记为 $a_t$）：由 $a_k \le a_p$ 得 $a_k + a_t \le a_p + a_t \le w$，仍然合法。组数不变，结论成立。

### 3. 最优子结构

设把 $a_j$ 按贪心分组后，剩下的元素构成子问题 $P'$，其最优解为 $S'$；令 $S = \{\text{贪心那一组}\} \cup S'$。若 $P$ 存在更优解 $Z$ 使 $|Z| < |S|$，由引理可把 $Z$ 改造成同样执行了这次贪心选择、组数不增的解 $Z'$。去掉贪心那一组后，$Z'$ 剩余部分仍是 $P'$ 的可行解，故 $|Z'| - 1 \ge |S'|$，即 $|Z'| \ge |S'| + 1 = |S|$，这与 $|Z| < |S|$ 矛盾。因此"贪心选择 + 子问题最优解"就是全局最优解，证毕。

### 4. 代码如何落地

- 用 `vector` 装所有价格，每轮 `pop_back()` 取出当前最大件；
- 在**排除最大件自身**的区间里用 `upper_bound` 找第一个 $> r$ 的位置，减一即"最后一个 $\le r$ 的元素"，也就是能装下的最大伙伴，找到就 `erase` 掉与之配对；
- 找不到伙伴就让它单独成组；`ans` 每轮自增一次，正好对应"最大件被处理掉"。

## 复杂度

设件数为 $n$。

- 时间：排序 $O(n \log n)$；之后每轮取出一个最大件（至多 $n$ 轮），轮内一次二分 $O(\log n)$，但 `vector::erase` 需要搬移元素，最坏 $O(n)$，故总时间复杂度为 $O(n^2)$（由代码可推断，瓶颈在 `erase`）。
- 空间：存价格与辅助变量，$O(n)$。

若把 `erase` 换成左右两个指针（一个指向最小、一个指向最大）向中间收缩，可去掉搬移开销，总复杂度降到 $O(n \log n)$，仅由排序决定。

## 参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int w, n;
    cin >> w >> n;
    vector<int> p(n);
    for (int i = 0; i < n; i++) cin >> p[i];
    if (n == 1) { cout << 1; return 0; }
    sort(p.begin(), p.end());

    int ans = 0;
    while ((int)p.size() > 1) {
        int r = w - p.back();
        if (r >= p[0]) {
            auto it = upper_bound(p.begin(), p.end() - 1, r) - 1;
            p.erase(it);
        }

        ans++;
        p.pop_back();
    }

    if (!p.empty()) ans++;

    cout << ans;
    return 0;
}
```

## 易错点

- **读入顺序**：代码是 `cin >> w >> n`，先组上限再件数（由代码可推断输入第一个数是 $w$）。写反了会得到完全错误的结果。
- **`upper_bound` 的区间右端必须是 `p.end() - 1`**：当前最大件正躺在 `p.back()`，若区间写成 `p.end()`，可能把最大件自己当成"伙伴"，变成自己和自己配对。
- **调用前必须判 `r >= p[0]`**：否则区间里不存在 $\le r$ 的元素，`upper_bound` 返回 `begin()`，再减一就落到 `begin()` 之前，属于未定义行为。
- **`it` 不能跨越 `erase` 使用**：伙伴取自 `[begin, end() - 1)`，所以 `it` 绝不会指向最大件本身；`p.erase(it)` 之后 `it` 立即失效，用完即弃，别保存下来复用。（顺手把 `pop_back` 提到 `erase` 前面其实也不影响正确性，`pop_back` 只让指向被弹元素和 `end()` 的迭代器失效。）
- **`n == 1` 的特判是冗余的**：去掉后主循环不执行，末尾 `if (!p.empty()) ans++` 一样会把答案补成 1。顺带一提，`n == 0` 时这段代码会输出 0。
- **别把三件塞进一组**：题目限定每组至多两件，`while` 每轮最多消耗两个元素，正好对应这个约束。
- **伙伴不是"最小件"**：别以为贪心一定是"最大配最小"，代码取的是"不超过 $r$ 的最大元素"；两者组数相同，但具体分组不同，按自己的实现写证明，别张冠李戴。
