# Snow Walking Robot 题解

## 题意

给定一个只由 `L`、`R`、`U`、`D` 组成的指令串 $s$，机器人从格点 $(0,0)$ 出发，按指令每次走一格（`L` 为 $x-1$，`R` 为 $x+1$，`U` 为 $y+1$，`D` 为 $y-1$）。

要求从 $s$ 中**删掉一些指令**，再**任意重排**剩下的指令（题面明确允许自己选择剩余指令的顺序，不要求是原串的子序列），得到的串满足：

1. 机器人执行完后回到 $(0,0)$；
2. 除 $(0,0)$ 外，任何格子都不能被经过两次或更多次；$(0,0)$ 也至多出现两次——只在开始和结束各出现一次，路径中间不允许再回到原点；
3. 保留下来的指令数尽量多。

输入第一行是测试组数 $q$，接下来 $q$ 行每行一个串 $s$；对每组数据输出两行：第一行是保留的指令条数 $k$，第二行是这 $k$ 条指令拼成的串（有多个最长方案时输出任意一种）。若一条都无法保留，第一行输出 `0`，第二行为空行。

既然顺序可以随意调整，删掉指令只意味着每个方向可用的条数不能超过 $s$ 中该方向的计数；代码正是按四个计数直接重建出 `L^l U^u R^l D^u`。

## 思路

### 一、回到原点：必须成对

设保留下来的指令中 `L`、`R`、`U`、`D` 分别有 $l',r',u',d'$ 条。水平位移是 $r'-l'$，竖直位移是 $u'-d'$，终点要落在原点，就必须

$$r' = l', \qquad u' = d'$$

这就是「成对」的由来：一条 `L` 只能被一条 `R` 抵消，竖直方向同理，任何单方向的指令都无法自己走回去。于是总长度 $k = 2l' + 2u'$，而可用量受原串计数限制：

$$l' \le \min(c_L,c_R) = l, \qquad u' \le \min(c_U,c_D) = u$$

由此得到长度上界

$$k \le 2l + 2u$$

这是任何合法方案都超不过去的天花板。注意它只是**上界**，下面还要讨论它是否达得到。

### 二、达到上界：沿矩形边界走一圈

当 $l>0$ 且 $u>0$ 时，按

$$L^{\,l}\;U^{\,u}\;R^{\,l}\;D^{\,u}$$

构造，即先向左 $l$ 步、再向上 $u$ 步、再向右 $l$ 步、最后向下 $u$ 步。这四条线段正好是以 $(0,0)$、$(-l,0)$、$(-l,u)$、$(0,u)$ 为顶点的轴对齐矩形的四条边，各走一次。

它不自交的理由很直接：$l>0$ 且 $u>0$ 时矩形面积为正，四条边两两只在相邻的端点处相接，不会在中途相交；每一段内部走过的格子都是全新的格子，因此除了「起点 = 终点」这一次重复外，没有任何格子被踩第二次。长度恰好 $2l+2u$，与上界相等，所以这种构造就是最优的。

### 三、退化情况：只有水平或只有竖直

若 $u=0$（竖直方向凑不出一对），继续套上面的式子会得到 $L^{l}R^{l}$。但此时矩形的「高」是 $0$，矩形退化成一条线段：向左走 $l$ 步再原路向右退回，中间那 $l-1$ 个格子会被踩两遍。$l\ge 2$ 时这明显非法；$l=1$ 时 `LR` 恰好合法，只是巧合。

更本质的理由：没有竖直移动时，整条路径被压在 $x$ 轴上，也就是一条**线**。在一条线上，从原点出发、最终回到原点、且中间格子不重复，最多只能向外走 $1$ 步再退回——一旦向外走 $2$ 步，退回时第 $1$ 步的格子必然要被再经过一次。所以线上的可行长度上限就是 $2$。只要 $l>0$，取一条水平配对就能达到这个上限，答案为 `LR`（`RL` 同样合法）。

竖直方向完全对称：$l=0,u>0$ 时答案是 `UD`，长度 $2$。

这就是**必须特判**的原因：通式 $2l+2u$ 在退化时给出 $2l$（或 $2u$）。当 $l\ge 2$（或 $u\ge 2$）时，这个长度既虚高、对应的串也不合法，必须压回 $2$；只有 $l=1$ 时通式恰好也给出合法的 `LR`，那是巧合，而特判分支同样覆盖了它。

### 四、两方向都没有

若 $l=0$ 且 $u=0$，任何移动都无法被抵消，唯一的合法选择是一条指令都不留，输出 `0` 与空行。

## 复杂度

单组数据：扫描一遍字符串统计四个方向计数，时间 $O(|s|)$；除输入串与输出串外只需 $O(1)$ 额外空间；输出的串长度至多 $2l+2u \le 2|s|$，退化分支只有 $2$ 个字符，输出规模同样是 $O(|s|)$。多组数据总时间复杂度为 $O(\sum |s|)$。

## 参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) {
        string s;
        cin >> s;

        int cL = 0, cR = 0, cU = 0, cD = 0;
        for (char c : s) {
            if (c == 'L') cL++;
            else if (c == 'R') cR++;
            else if (c == 'U') cU++;
            else if (c == 'D') cD++;
        }

        int l = min(cL, cR);
        int u = min(cU, cD);

        if (l > 0 && u > 0) {
            // 矩形边界：长度达到上界 2l + 2u 且不自交
            cout << 2 * l + 2 * u << '\n';
            cout << string(l, 'L') << string(u, 'U') << string(l, 'R') << string(u, 'D') << '\n';
        } else if (l > 0) {
            // 只有水平：一条线上一去一回，最多 2 步
            cout << 2 << '\n';
            cout << "LR" << '\n';
        } else if (u > 0) {
            // 只有竖直：同理
            cout << 2 << '\n';
            cout << "UD" << '\n';
        }
        else {
            // 凑不出任何一对，只能不动
            cout << 0 << '\n';
            cout << '\n';
        }
    }
    return 0;
}
```

## 易错点

- **两行输出，顺序不能反**：先输出条数，再输出串。`l=u=0` 时第二行是空串，代码会输出一个空行（题面允许省略这一行，输出出来也无害）。
- **只用单方向计数**：例如只取 $\min(c_U,c_D)$ 条 `U` 就直接输出，这样回不到原点。必须两边各取 $\min$，长度是配对数目的两倍。
- **忘记退化特判**：直接输出 `L^l R^l` 或 `U^u D^u`，当 $l$（或 $u$）$\ge 2$ 时会原路返回、踩重格子；同时把长度写成 $2l$（或 $2u$）也与实际合法长度 $2$ 不符。
- **长度与串不一致**：退化分支的长度是 $2$，不是 $2l$；两个数字必须和实际输出的字符数相等。
- **拼接顺序不能乱**：像 `L R U D` 这种拼法会让机器人中途回到原点（`LR` 已经回到 $(0,0)$，接着 `UD` 又回到 $(0,0)$），而原点只允许出现在路径的最开始和最末尾。正确写法是 `L^l U^u R^l D^u`（或对称的绕行方式），保证绕矩形一圈。
- **把上界当成答案**：$2l+2u$ 只由矩形构造在 $l,u$ 都为正时达到；若只有一个方向能凑成对（另一个方向为 $0$），上界不可达，真实最优值是 $2$，而不是 $2l+2u$；若两个方向都凑不出对（$l=u=0$），上界本来就是 $0$，输出空串即可。
- **多组数据**：计数变量必须在每组开始时清零（代码中定义在循环体内），否则上一组的数据会污染下一组。

## 总结

本题的关键不是搜索或模拟，而是先做**上界分析**：回原点迫使两个方向各自成对，于是长度不超过 $2\min(c_L,c_R)+2\min(c_U,c_D)$；再给出达到上界的**构造**（绕矩形边界一圈），并单独处理上界不可达的退化情形（路径被压成一条线，只能一去一回，长度上限为 $2$）。先证上界、再构造，是这类「删指令 + 求最长合法」题目最稳的切入点。
