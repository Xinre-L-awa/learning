# Creating Keys for StORages Has Become My Main Skill 题解

## 题目大意

给定 `n` 和 `x`，构造一个长度为 `n` 的数组 `a`，满足：

1. `a[1] | a[2] | ... | a[n] = x`（按位或等于 `x`）；
2. 在所有满足条件的数组中，`MEX({a[1], a[2], ..., a[n]})` 尽可能大。

输出任意一个合法数组。

- `1 ≤ n ≤ 2·10^5`
- `0 ≤ x < 2^30`
- 所有测试用例的 `n` 之和不超过 `2·10^5`

---

## 核心观察

### 观察 1：每个元素都必须是 `x` 的“子掩码”

因为最终按位或等于 `x`，如果某个 `a[i]` 含有 `x` 中为 `0` 的二进制位，那么最终按位或必然包含 `x` 之外的位，无法等于 `x`。

所以对任意 `a[i]`，必须满足：

```
a[i] | x = x
```

### 观察 2：第一个不满足 `i | x = x` 的数不能出现

设 `k` 是从小到大第一个满足 `(k | x) != x` 的非负整数。

那么 `k` 本身不能出现在数组中，因此：

```
MEX ≤ k
```

### 观察 3：为了让 MEX 最大，应尽量依次放入 `0, 1, 2, ...`

因为 `MEX` 要求从 `0` 开始的连续整数都存在，所以最优策略是：

- 能放 `0` 就放 `0`；
- 能放 `1` 就放 `1`；
- 依次类推，直到遇到第一个不能放的数 `k`。

---

## 构造方法

### 第一步：找 `k`

从 `0` 开始，找到第一个满足：

```
(k | x) != x
```

的 `k`。如果 `0 ~ n-1` 全部满足 `(i | x) == x`，则令 `k = n`。

---

### 第二步：分类构造

#### 情况一：`k < n`

说明 `k` 不能出现，`MEX` 最大就是 `k`。

构造：

```
a = [0, 1, 2, ..., k-1, x, 0, 0, ..., 0]
```

- 前 `k` 个元素是 `0 ~ k-1`；
- 第 `k+1` 个元素放 `x`，保证最终按位或等于 `x`；
- 剩余 `n-k-1` 个位置补 `0`。

因为 `0 ~ k-1` 都是 `x` 的子掩码，它们的按位或仍然是 `x` 的子掩码，再或上 `x`，最终结果一定等于 `x`。

数组中包含 `0 ~ k-1`，不包含 `k`，所以 `MEX = k`，达到最大值。

---

#### 情况二：`k == n`

说明 `0 ~ n-1` 全部是 `x` 的子掩码。

计算前缀按位或：

```
pref = 0 | 1 | 2 | ... | (n-1)
```

##### 子情况 2.1：`pref == x`

直接输出：

```
a = [0, 1, 2, ..., n-1]
```

此时数组包含 `0 ~ n-1`，`MEX = n`，达到长度上限，最优。

##### 子情况 2.2：`pref != x`

如果全部放入 `0 ~ n-1`，最终按位或就不是 `x`，所以必须舍弃一些数。

保留 `0 ~ n-2`，把最后一个位置改成 `x`：

```
a = [0, 1, 2, ..., n-2, x]
```

此时：

- 最终按位或一定等于 `x`（因为最后一个是 `x`）；
- 数组包含 `0 ~ n-2`，不包含 `n-1`，所以 `MEX = n-1`。

由于不能包含 `0 ~ n-1` 全部（否则按位或不是 `x`），`MEX` 不可能达到 `n`，所以 `MEX = n-1` 已经是最大值。

---

## 正确性证明

1. **合法性**：所有元素都是 `x` 的子掩码，因此不会产生 `x` 之外的二进制位；构造中至少有一个元素等于 `x`（情况一）或整体按位或等于 `x`（情况二），因此最终按位或一定等于 `x`。

2. **MEX 最优性**：
   - 情况一：`k` 不能出现，`MEX ≤ k`；构造包含 `0 ~ k-1`，所以 `MEX = k`，最优。
   - 情况二子情况 2.1：`MEX ≤ n`（数组长度限制）；构造包含 `0 ~ n-1`，所以 `MEX = n`，最优。
   - 情况二子情况 2.2：若 `MEX = n`，则必须包含 `0 ~ n-1`，但那样按位或不是 `x`，矛盾。所以 `MEX ≤ n-1`；构造包含 `0 ~ n-2`，所以 `MEX = n-1`，最优。

---

## 复杂度分析

- 每个测试用例只需要遍历数组一次；
- 总时间复杂度 `O(Σn)`；
- 空间复杂度 `O(n)`（也可以边计算边输出，做到 `O(1)` 额外空间）。

满足题目限制。

## 参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--) {
        int n, x;
        cin >> n >> x;

        // 找第一个不满足 (i | x) == x 的位置
        int k = 0;
        while (k < n && (k | x) == x) k++;

        if (k < n) {
            // 前 k 个放 0, 1, ..., k-1
            for (int i = 0; i < k; i++) cout << i << ' ';
            // 第 k 个放 x
            cout << x << ' ';
            // 剩余补 0
            for (int i = k + 1; i < n; i++) cout << 0 << ' ';
            cout << '\n';
        } else {
            // 0 ~ n-1 都是 x 的子掩码
            int pref = 0;
            for (int i = 0; i < n - 1; i++) {
                cout << i << ' ';
                pref |= i;
            }

            // 判断 0 ~ n-1 的按位或是否等于 x
            if ((pref | (n - 1)) == x) {
                cout << n - 1 << '\n';
            } else {
                cout << x << '\n';
            }
        }
    }

    return 0;
}
```

---

## 易错点提醒

1. **运算符优先级**：`k | x == x` 会先算 `x == x`，必须写成 `(k | x) == x`。
2. **`k` 的含义**：`k` 是第一个不能出现的数，而不是最后一个能出现的数，构造时注意边界。
3. **情况二要先判断前缀按位或**：不能无条件把最后一个改成 `x`，否则会损失本可以保留的 `n-1`，导致 MEX 不是最大。
4. **补零数量**：情况一中第 `k+1` 个位置放 `x`，剩余 `n-k-1` 个位置补 `0`，不要算错。

---

## 总结

| 情况 | 构造 | MEX |
|------|------|-----|
| `k < n` | `0,1,...,k-1, x, 0,...,0` | `k` |
| `k == n` 且 `pref == x` | `0,1,...,n-1` | `n` |
| `k == n` 且 `pref != x` | `0,1,...,n-2, x` | `n-1` |

本题是一道**以位运算为背景的贪心构造题**，核心在于利用「子掩码」性质和 MEX 的连续性进行贪心构造。
