# 最长子序列 题解

## 题意

读入长度 $n$ 和一个字符串 $s$，求 $s$ 的**最长不下降子序列**长度：选出下标严格递增的一串位置 $i_1<i_2<\dots<i_k$，使得
$$s_{i_1}\le s_{i_2}\le\dots\le s_{i_k},$$
要求 $k$ 最大。注意条件是「不下降」而不是「严格上升」，相邻两项**允许相等**，所以代码里写的是 `s[j] <= s[i]`（带等号）。

输入格式由代码可推断为 `cin >> n >> s`：先读整数 $n$，再读一个不含空白的字符串 $s$。数据范围题目未给出，两份代码分别按 $O(n^2)$ 与 $O(n\log n)$ 设计；$O(n^2)$ 版把 $n$ 当作循环上界，因此要求 $n$ 与字符串长度一致，$O(n\log n)$ 版则只把 $n$ 读进来、实际按字符串长度遍历。

## 思路

### 一、$O(n^2)$ 的 dp

设 $dp_i$ 表示**以 $s_i$ 结尾**的最长不下降子序列长度。任何长度大于 $1$、以 $s_i$ 结尾的合法子序列，去掉末项后就是一个以某个 $s_j$（$j<i$）结尾、且满足 $s_j\le s_i$ 的合法子序列，于是
$$dp_i=\max\Bigl(1,\ \max_{j<i,\ s_j\le s_i}\bigl(dp_j+1\bigr)\Bigr),\qquad ans=\max_{0\le i<n} dp_i .$$

为什么这个方程不需要关心 $dp_j$ 那条子序列内部长什么样？因为「能不能接上 $s_i$」只取决于它的**最后一个字符**，而这正是 $dp_j$ 的定义所保证的：$dp_j$ 对应的子序列确实以 $s_j$ 结尾。既然对所有合法 $j$ 取 $\max$，谁给出更长的链就选谁，两个候选 $j_1,j_2$ 之间的相对大小关系（$s_{j_2}<s_{j_1}$ 还是相反）不影响结果——方程对每个 $j$ 都独立成立，取最大值就把它们全部覆盖了。换句话说，状态把「子序列的全部信息」压缩成了「结尾字符 + 长度」，而转移只需要这两样。

### 二、$O(n\log n)$ 的 tails 数组

把状态从「按结尾位置」换成「按长度」：设 $tails[k]$ 表示**所有长度为 $k+1$ 的不下降子序列中，结尾字符的最小值**（下标从 $0$ 开始，因此 $tails$ 的长度就是当前的答案）。

**单调性**：$tails$ 天然单调不降，即 $tails[0]\le tails[1]\le\dots$。

*证明*：反设存在 $k$ 使 $tails[k+1]<tails[k]$。取那个长度为 $k+2$、结尾为 $tails[k+1]$ 的子序列，删掉末项，得到长度 $k+1$、结尾值不超过 $tails[k+1]$ 的合法子序列。于是 $tails[k]\le tails[k+1]$，与假设矛盾。正因为有序，才能在上面二分。

**插入规则**：设当前字符为 $ch$，令
$$idx=\texttt{upper\_bound}(tails,\ ch)=\min\{\,t\mid tails[t]>ch\,\}.$$
$tails[0..idx-1]$ 都 $\le ch$，所以把 $ch$ 接在「长度 $idx$、结尾 $tails[idx-1]$」的子序列后面（$idx=0$ 时取空序列，$ch$ 单独成串），得到长度 $idx+1$、结尾 $ch$ 的合法子序列；而 $ch<tails[idx]$，于是 $tails[idx]$ 可以被压低为 $ch$。若 $idx$ 等于数组长度，说明所有 $tails$ 都 $\le ch$，直接追加，答案 $+1$。

$idx$ 恰好是「以 $ch$ 结尾的最长不下降子序列长度 $-1$」：注意 $tails[k]\le ch$ 当且仅当存在长度 $k+1$、每个元素都 $\le ch$ 的合法子序列，所以「$tails$ 中恰有 $idx$ 个元素 $\le ch$」等价于「已处理前缀里最长的、每个元素都 $\le ch$ 的不下降子序列长度恰为 $idx$」。于是以 $ch$ 结尾最多只能到长度 $idx+1$（上界），而上面的构造说明这个上界可达（下界），所以每次落点都是精确的。

**为什么是 `upper_bound` 而不是 `lower_bound`**：

- 不下降**允许相等**。若已有长度 $k+1$、结尾恰为 $ch$ 的子序列，$ch$ 完全可以接在它后面变成 $k+2$。`upper_bound` 找的是「第一个 $>ch$ 的位置」，等于 $ch$ 的元素会被跳过，$ch$ 落在它们之后一位，长度因此增加。例：`s = "aaa"`，三次都命中「找不到更大的」分支而追加，结果为 $3$。
- 若求**严格上升**，上一位必须严格小于 $ch$，末尾为 $ch$ 的那些子序列就接不上了，只能替换，于是应改用 `lower_bound`（第一个 $\ge ch$ 的位置）。同样 `"aaa"` 在严格上升下答案为 $1$。

一句话：`upper_bound` 让「相等」算作可以延长，`lower_bound` 让「相等」只能覆盖。两者只差一个等号，答案却可能相差很多，这是本题最容易写反的地方。

## 复杂度

| 解法 | 时间 | 空间 |
| --- | --- | --- |
| $O(n^2)$ dp | $O(n^2)$ | $O(n)$ |
| tails + 二分 | $O(n\log n)$ | $O(n)$（`tails` 长度不超过 $n$） |

$O(n\log n)$ 版对每个字符做一次二分，二分对象是有序的 `tails`；`char` 可直接比较，无需离散化。

## 参考代码（C++17）

下面是 `ans O(nlogn).cpp` 的完整代码，与文件逐行一致（仅省略了文件开头的两行 `//` 注释）。`ans O(n^2).cpp` 那版带有一处 $n=1$ 的边界 bug（见「易错点」第 1 条），所以这里只给出这一份可正确运行的实现。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;      // 长度
    string s;   // 字符串
    cin >> n >> s;

    // tails[k] 表示"长度为 k+1 的不下降子序列"的结尾字符的最小值
    // 这个数组天然单调不降，因此可以二分
    vector<char> tails;

    for (char ch : s) {
        // 不下降允许相等，所以找第一个严格大于 ch 的位置替换
        // （若求严格上升子序列，这里应改用 lower_bound）
        auto it = upper_bound(tails.begin(), tails.end(), ch);
        if (it == tails.end()) tails.push_back(ch);
        else *it = ch;
    }

    cout << tails.size();

    return 0;
}
```

## 易错点

1. **$n=1$ 时 $O(n^2)$ 版会输出 $0$**。原代码把初值放在循环之前，却让 `ans` 从 `0` 起步、循环从 `i = 1` 开始（摘自 `ans O(n^2).cpp`）：

   ```cpp
   dp[0] = 1;
   int ans = 0;                       // 初值是 0
   for (int i = 1; i < n; i++) {      // 从 1 起，n = 1 时循环体不执行
       dp[i] = 1;
       for (int j = 0; j < i; j++)
           if (s[j] <= s[i]) dp[i] = max(dp[i], dp[j] + 1);
       ans = max(ans, dp[i]);
   }
   ```

   `ans` 只在循环体内被更新，而 `i = 1..n-1` 一次都不执行时循环体整体被跳过，`ans` 保持 $0$，于是单字符输入会打印 $0$ 而不是 $1$。注意 $n\ge 2$ 时这个 bug **不显现**：每个 $dp_i\ge 1$ 都 $\ge dp_0$，取 $dp_1..dp_{n-1}$ 的最大值已经等于真正的答案，所以它只在最小数据上炸，很有迷惑性。修法有两种：把 `ans` 初值写成 `1`（或 `dp[0]`），或者在循环前补一句 `ans = max(ans, dp[0]);`。
2. **等号漏写就变成了另一道题**。判定条件写成 `s[j] < s[i]`、或者二分写成 `lower_bound`，求的都是严格上升子序列；字符串里重复字符很常见，答案会偏小甚至差很多。写完后用全同字符（如 `"aaaa"`）自测：不下降应得 $n$，严格上升应得 $1$。
3. **`tails` 不是子序列本身**。替换操作会把字符放到不属于它的位置上，`tails` 里存的内容并非 $s$ 的一个合法子序列，只有它的**长度**是答案。要输出具体方案，必须另外记录前驱或下标，不能直接打印 `tails`。
4. **$O(n\log n)$ 版实际上按字符串长度遍历**（`for (char ch : s)`），读入的 `n` 并未参与循环，所以它天然没有 $n=1$ 的边界问题；而 $O(n^2)$ 版用 `i < n` 作上界并访问 `s[i]`，只有输入保证 $n$ 与 `s.size()` 一致时才安全（由代码可推断二者一致）。
5. **单点替换不要写成追加**。`if (it == tails.end())` 与 `else` 两个分支缺一不可：少了追加则答案永远不变，少了替换则退化成「统计有多少个字符能接在末尾」，都不对。

## 总结

$O(n^2)$ 的 dp 顺着「以 $i$ 结尾」来想，状态数 $n$、转移枚举 $n$，直观但慢；$O(n\log n)$ 把状态重排成「长度为 $k$ 的最小结尾」，从而让状态数组自带单调性，用一次二分代替一层枚举。二者的答案定义一致，区别只在压缩状态的方式，而「不下降」与「严格上升」的差别全部集中在用的是 `upper_bound` 还是 `lower_bound` 上。
