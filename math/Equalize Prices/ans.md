# Equalize Prices 题解

## 题意

给定一个长度为 $n$ 的数组 $a$，以及一个非负整数 $k$。允许对每个元素 $a_i$ 独立地做一次修改，改成任意一个满足

$$|a_i' - a_i| \le k$$

的整数 $a_i'$（即 $a_i'$ 可以是 $[a_i-k,\ a_i+k]$ 内的任意整数）。修改完成后要求所有元素都相等，设这个共同的值为 $B$。

求能实现的最大 $B$；如果无论怎么改都无法让全部元素相等，输出 $-1$。

由代码可推断：输入包含 $t$ 组测试数据，每组先读 $n,k$，再读 $n$ 个数组元素，结果按组逐行输出。

## 思路

### 第一步：把「能变成什么」写成区间

对单个元素 $a_i$ 来说，它能取到的所有值恰好是一个区间：

$$a_i' \in [a_i - k,\ a_i + k]$$

因为 $k \ge 0$，这个区间永远非空（至少能取到 $a_i$ 本身）。

### 第二步：全部相等等价于区间有公共点

要让所有元素都等于同一个 $B$，就必须存在一个数同时落在**所有**区间里，即

$$B \in \bigcap_{i=1}^{n} [a_i - k,\ a_i + k]$$

一维情况下，若干区间的交集仍是区间，且交集的左端点是所有左端点的最大值、右端点是所有右端点的最小值：

$$\bigcap_{i} [a_i-k,\ a_i+k] = \left[\ \max_i (a_i-k),\ \min_i (a_i+k)\ \right] = \left[\ a_{\max}-k,\ a_{\min}+k\ \right]$$

因此可行性只取决于两个极端值：$a_{\max}$ 和 $a_{\min}$。

### 第三步：交集非空的条件

交集 $\left[a_{\max}-k,\ a_{\min}+k\right]$ 非空，当且仅当左端点不超过右端点：

$$a_{\max} - k \le a_{\min} + k \quad \Longleftrightarrow \quad a_{\max} - a_{\min} \le 2k$$

这一步的直观解释：最小值需要往上抬，最多抬 $k$；最大值需要往下压，最多压 $k$；两者要能碰到一起，就需要它们之间的距离不超过两边可移动量之和 $2k$。中间的元素夹在 $a_{\min}$ 和 $a_{\max}$ 之间，只要两个端点能对齐，它们也一定能对齐，所以不需要单独检查。

### 第四步：答案取哪个数

当条件 $a_{\max}-a_{\min} \le 2k$ 成立时，合法的 $B$ 是一个完整的区间 $\left[a_{\max}-k,\ a_{\min}+k\right]$，题目要求最大的 $B$，自然取这个区间的右端点：

$$B_{\max} = a_{\min} + k$$

**为什么不是别的数？** 因为 $a_{\min}$ 这个元素能动到的最大值就是 $a_{\min}+k$，而其他元素都能覆盖到它（条件保证），所以 $a_{\min}+k$ 一定可行。同时任何一个 $B > a_{\min}+k$ 都超出了 $a_{\min}$ 的上限，无论怎么改都做不到，于是 $a_{\min}+k$ 就是上界也是可达值，答案唯一确定，不需要二分。

### 第五步：实现

把数组排序，$a_{\min} = a_0$，$a_{\max} = a_{n-1}$，直接套上面两条结论即可：

- 若 $a_{n-1} - a_0 > 2k$，输出 $-1$；
- 否则输出 $a_0 + k$。

因为只用到最小值和最大值，排序其实不是必需的，写排序是为了顺便让 $a_{\min}/a_{\max}$ 的取值一目了然。

## 复杂度

- 时间复杂度：每组 $\mathcal{O}(n \log n)$，来自排序；判定与输出是 $\mathcal{O}(1)$。
- 空间复杂度：$\mathcal{O}(n)$，用于存储数组。

## 参考代码（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t-- > 0) {
        ll n, k;
        cin >> n >> k;

        vector<ll> a(n);
        for (int i = 0; i < n; i++) cin >> a[i];

        sort(a.begin(), a.end());
        if (a[n - 1] - a[0] > 2 * k) {
            cout << -1 << '\n';
            continue;
        }

        cout << a[0] + k << '\n';
    }

    return 0;
}
```

## 易错点

- **判定要用 $a_{\max}-a_{\min} > 2k$，而不是 $\ge 2k$**。当差值恰好等于 $2k$ 时，交集退化成单个点 $a_{\min}+k = a_{\max}-k$，仍然可行，答案照样是 $a_{\min}+k$，不能输出 $-1$。
- **答案不要用二分或中位数去猜**。合法 $B$ 的集合是连续区间，最大值就是右端点 $a_{\min}+k$，取中位数、取平均值都会得到偏小或非法的值。
- **只检查相邻差值不够**。真正起作用的只有全局最大值与最小值之差；若逐个检查相邻元素，会漏掉「跨度超限」的整体情况。
- **溢出与类型**。$a_i$ 与 $k$ 都用 `long long` 读入，`2 * k` 与 `a[n-1] - a[0]` 便不会在比较时溢出。
- **多组测试数据的循环**。整段逻辑必须放在 `while (t-- > 0)` 内部，数组也要在循环内重新构造，避免上一组数据残留。
- **$n=1$ 无需特判**。此时差值为 $0 \le 2k$ 恒成立，按公式输出 $a_0 + k$ 正好是最优（该元素能取到的最大值），无需额外分支。
- **别把同目录的 `ANSANS.CPP` 当作本题代码**。它处理的是另一道题，输入输出格式与本题完全不同，详见下面的说明。

## 总结

本题的核心是把「每个元素能变成哪些值」翻译成一个区间，然后再把「全部变成同一个数」翻译成「这些区间有公共点」。区间有公共点的判据在一维下极其简单：左端点的最大值不超过右端点的最小值。于是问题从修改方案的选择退化成一次比较：

$$a_{\max} - 2k \le a_{\min} \iff \text{可行}$$

可行时最大的公共点正是最紧的那个上界 $a_{\min}+k$。这类「每个变量自由取值、要求全部相同」的题目，通常都可以先写成区间再取交，交集的端点直接给出答案和可行性判据。

## 说明

同目录下的 `ANSANS.CPP` **不是本题的代码**，它统计的是「字符串中只由可用字母构成的连续段，其所有子段数量之和」。其做法是：遍历字符串，遇到可用字母就让当前连续段长度 `len` 加一，遇到不可用字母就把这一段结算掉——长度为 $len$ 的连续段贡献 $\frac{len \times (len+1)}{2}$ 个子段，把它累加到 `long long` 型的 `ans` 中；循环结束后还要补算末尾那一段。因此它的输入是 $n,k$ 与一个字符串加 $k$ 个字符，与本题完全无关，阅读时注意区分，不要混淆。
